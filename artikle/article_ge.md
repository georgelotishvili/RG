# *რეფრაქციული გრავიტაცია: ფაზური ველის თეორია*

## *მოკლე შინაარსი*

*წინამდებარე ნაშრომში რეფრაქციული გრავიტაცია (RefG) ფორმულირებულია როგორც მეტრიკულ გრავიტაციაზე დაშენებული ფაზური, ეფექტური ველის თეორია (EFT). მოქმედების ბირთვს აინშტაინ-ჰილბერტის წევრი წარმოადგენს, ხოლო დამატებითი სექტორი მოიცავს ერთ ფაზურ სკალარს `Phi`, მედიუმის სამ სივრცულ სკალარს `phi^A` და მათ ფაზა-სივრცულ შეწყვილებას. მინიმალური ტრანკაცია აერთიანებს `G2(X)` ტიპის ფაზურ სექტორს, solid-EFT ტიპის სივრცულ მედიუმს და `Y I1` ჯვარედინ წევრს. ამავე ინვარიანტების კომბინაციით განისაზღვრება შევსების განშტოება, რომელიც მინიმალურ ბირთვს ΛCDM/1PN თავსებად რეჟიმამდე აფართოებს.*

*სახელწოდება „რეფრაქციული გრავიტაცია“ აღნიშნავს კონკრეტულ მექანიზმს: სუსტი, სტატიკური და გასაშუალოებული რეჟიმისათვის მოქმედებიდან მიღებული სივრცული სტრესი უკავშირდება ერთ ეფექტურ ცვლადს `h_eff`, ხოლო მატერიის მინიმალური მეტრიკული ბმა იძლევა `n_eff=exp(h_eff)` რეფრაქციულ ინდექსს. ამ ჯაჭვში ნიუტონის ლოკალური არხი მოდის Bernoulli-რადიალური პასუხიდან, ხოლო კოჰერენტული ვორტექსული არხი იძლევა MOND/BTFR ზღვარს.*

*მინიმალური ტრანკაცია განსაზღვრავს თეორიის საწყის ბირთვს. ამ ბირთვში მიიღება `Y=-2X` ნიშანთა სისტემის თარგმანი, მინიმალური მოქმედება, კინეტიკური სტაბილურობის აუცილებელი არე ერთგვაროვან ფონზე, სიმკვრივისა (`rho`) და წნევის (`p`) ფორმები FLRW მეტრიკაში, ბიანკი-ნოეთერის იდენტობა, დინამიკური ფაზური საათის დენის განტოლება, სტატიკური სფერული 1PN კოეფიციენტური შტო და სუსტი ველის რეფრაქციული ჯაჭვი. ამავე ბირთვიდან მიიღება no-go ლემა: მუდმივ-კოეფიციენტიანი მინიმალური თეორია ერთდროულად ვერ იძლევა ზუსტ ΛCDM ფონსა და მზის სისტემის 1PN თავსებადობას სტაბილურ არატრივიალურ სექტორში. ამ შეზღუდვის მოსახსნელად გამოიყენება შევსების განშტოება `S=Y+2I1-I3=6`, რომელიც მინიმალურ თეორიას ΛCDM/1PN თავსებად რეჟიმამდე აფართოებს და თვითნებურ დამატებას არ წარმოადგენს.*

*მინიმალური იზოტროპული 2PN განშტოება არ არის კალიბრირებული `S=6` თეორიის მზის-სისტემური პროგნოზი. ბნელი-ენერგიის მასშტაბზე კალიბრირებული `S=6` შევსების პირდაპირი მზის წვლილი `~10^-35` რიგამდე ჩაცხრება. შესაბამისად, მზის 2PN სექტორში მიღებული შედეგი არის GR-თან თავსებადობა, `q_2PN=7/4 + O(10^-35)`, ხოლო სრული თვით-თანმიმდევრული გარე ODE ამ შედეგის შემდგომი გამკაცრების გზაა.*

*გალაქტიკურ ზღვარში RefG იძლევა ორარხიან სუსტი ველის შედეგს. ფაზური კოჰერენტობა აჩქარების მასშტაბს აფიქსირებს როგორც `a0=cH/(2*pi)`: `2*pi` არის სრული ფაზური ციკლის ნორმალიზაცია. ვარიაციული ვორტექსული დატვირთვა იძლევა `g_v/g_N=a0/g` კანონს, აქედან `mu(x)=x/(1+x)`, ხოლო deep-MOND ზღვარში მიიღება BTFR. კოჰერენტული უჯრედის რადიუსი `R_coh=c^2/a0` წყვეტს უსასრულო ლოგარითმულ კუდს და გარეთ თრგუნავს ვორტექსულ წვლილს. ლოკალურ p10 არხში პირველი რიგი არჩევს ბიკონფორმულ განშტოებას, Bernoulli წყარო ცენტრში სასრულდება, ნიუტონის კოეფიციენტი ასიმპტოტური მუხტით ფიქსირდება, ხოლო კვადრატული წნევითი ფუნქცია TOV-ის ხაზოვან წყაროში თავისი წარმოებულით შედის.*

## *1. შესავალი*

*გრავიტაციის თანამედროვე აღწერა მეტრიკულ გეომეტრიას ეყრდნობა. ზოგადი ფარდობითობის თეორია მაღალი სიზუსტით ხსნის მზის სისტემის ტესტებს, პულსართა დინამიკას, გრავიტაციულ ტალღებსა და კოსმოლოგიური სტანდარტული მოდელის გეომეტრიულ ბირთვს. წინამდებარე ნაშრომში წარმოდგენილი კონსტრუქცია სრულად ინარჩუნებს მეტრიკულ-გეომეტრიულ ბირთვს: აინშტაინ-ჰილბერტის წევრს, სინათლის კონუსის მეტრიკულ განსაზღვრებას და მატერიის მინიმალურ მეტრიკულ კავშირს. ამ ბირთვზე იგი აშენებს კონტროლირებულ ეფექტური ველის თეორიის (EFT) სექტორს. ახალი სექტორის როლი მოქმედებაში, ფონურ განტოლებებსა და დაკვირვებით კრიტერიუმებში მკაფიოდ გამიჯნული და დამოუკიდებლად შემოწმებადია.*

*რეფრაქციული გრავიტაცია (RefG) ემყარება ეფექტური ველის სტანდარტულ ლოგიკას: გრავიტაციული პასუხის გაფართოება მოქმედებაში დამატებითი ველების, ინვარიანტებისა და ფონური წევრების შემოტანით მიიღწევა. RefG ამ ჩარჩოს იზიარებს და მის ფიზიკურ შინაარსს ფუძე-მედიუმის ფაზური ველებით განსაზღვრავს. მატერია ცვლის ამ ფუძის ეფექტურ მდგომარეობას, რაც გარე აღწერაში დროისა და მანძილის სკალების, წნევითი პასუხისა და გავრცელების კოორდინატული თვისებების ცვლილებად ვლინდება. თეორიის მტკიცებები მოქმედებიდან, ინვარიანტებიდან და განშტოებათა ალგებრიდან გამომდინარეობს.*

*რეფრაქციული აღწერა წინამდებარე სტატიაში ვარიაციული ფორმალიზმის ენაზე ყალიბდება. შედეგები განისაზღვრება მოქმედების ვარიაციით, ველთა არჩევით, ინვარიანტების სტრუქტურითა და განშტოებათა ალგებრით. ამიტომ ნაშრომში მოყვანილი ფიზიკური მტკიცებები ეყრდნობა მოქმედებიდან მიღებულ ფონურ განტოლებებს, ლოკალური სტაბილურობის კრიტერიუმებსა და დაკვირვებით შემოწმებად ნაშთებს.*

*სტატიის ფორმატი არ იძლევა RefG-ის ყველა სექტორის სრულ განხილვას. ამიტომ ნაშრომი შემოიფარგლება მინიმალური თვითკმარი ბირთვით: მოქმედება, მინიმალური ტრანკაცია, no-go ლემა, `S=6` თავსებადობის განშტოება, მზის სისტემის 1PN/2PN ზღვარი, ტენზორული ტალღის სიჩქარე, ლოკალური სტაბილურობა და სუსტი ველის რეფრაქციული ჯაჭვი. გალაქტიკური დინამიკის სფერული სუსტი ველის ბირთვი ნაშრომში შედის; დისკური curl-შესწორებები, სრული SPARC ალბათობითი მორგება, ნაწილაკოვანი ბნელი მატერიის გარეშე აქტიური CMB, ძლიერი ველი, კომპაქტური ობიექტები და ნაწილაკური სპექტრი ცალკე კვლევით სექტორებად რჩება.*

## *2. მთავარი შედეგები*

*სტატიის ცენტრალური შედეგი სამ ნაწილად იყოფა. პირველი არის no-go ლემა: შვიდწევრიანი მუდმივ-კოეფიციენტიანი მინიმალური ბირთვი ერთდროულად ვერ აკმაყოფილებს ზუსტ ΛCDM ფონურ დახურვას, მზის 1PN უსტრესო პირობას და არატრივიალურ სტაბილურობას. ამიტომ შევსება არ არის დეკორატიული დამატება; იგი მინიმალური ბირთვის აუცილებელ გაფართოებად ჩნდება.*

*მეორე არის თავსებადობის თეორემა. შევსების სექტორში არსებობს საერთო განშტოება:*

```text
S = Y + 2 I1 - I3,
S = 6.
```

*FLRW ფონზე აღნიშნული განშტოება უზრუნველყოფს დადებით დინამიკურ საათს `Y=6-6/a^2+1/a^6` და ზუსტ ΛCDM ფონურ ევოლუციას. აქ `rho_0` არის Λ-სიდიდის საწყისი პარამეტრი, ისევე როგორც კოსმოლოგიური მუდმივა GR-ში; ნაშრომი Λ-სიდიდის გამოყვანას არ აცხადებს. სტატიკურ მზის-სისტემურ 1PN ფონზე ეს ინვარიანტი ტოვებს მხოლოდ ერთგვაროვან Λ-ტიპის სტრესს და არ წარმოქმნის `O(U)` რიგის ლოკალურ ნაშთს.*

*მესამე არის 2PN სექტორის გამიჯვნა. მინიმალურ იზოტროპულ უსტრესო დახურვაში არსებობს ცალკე არატრივიალური განშტოება, მაგრამ ის არ არის კალიბრირებული `S=6` შევსების მზის პროგნოზი. ბნელი-ენერგიის მასშტაბზე კალიბრირებული `S=6` შევსების ლოკალური წვლილი `Lambda R_sun^2 ~ 5 * 10^-35` რიგამდეა ჩახშობილი. ამდენად მზის 2PN სექტორში მთავარი ფიზიკური დასკვნა არის GR-თან თავსებადობა მასშტაბური არგუმენტით; სრული ODE ამოხსნა ამ დასკვნის შემდგომ გამკაცრებას ემსახურება.*

*შემდგომ თავებში ეს შედეგები ერთიანდება `G2(X)` + solid-EFT ტრანკაციასთან, ლოკალური სტაბილურობის ანალიზთან, უპირატესი ჩარჩოს `alpha_i=0` ჯაჭვთან და CMB-ის ერთნაირი შეყვანის თანმიმდევრულობის იდენტობასთან. დაკვირვებითი და ფორმალური შემოწმებების შეჯამება მოცემულია მე-18 პარაგრაფში.*

## *3. კავშირი არსებულ ჩარჩოებთან*

*RefG ინარჩუნებს აინშტაინ-ჰილბერტის გეომეტრიულ ბირთვს: მოქმედებაში რჩება წევრი $M_{\text{Pl}}^2 R/2$, ხოლო დამატებითი სექტორი იწერება ეფექტური ლაგრანჟიანით. მეტრიკა კვლავ განსაზღვრავს დროს, მანძილს, სინათლის კონუსსა და მატერიის მინიმალურ ბმას (minimal coupling). ახალი სექტორი მეტრიკულ წყაროს ფაზურ და სივრცული მედიუმის ეფექტურ სტრესს ამატებს.*

*ჰორნდესკის, განზოგადებული გალილეონის (generalized Galileon), DHOST-ისა და ბნელი ენერგიის ეფექტური ველის ფორმალიზმებთან კავშირი ფაზური სექტორის საშუალებით ფიქსირდება [1-3,18-23]. RefG-ში ფაზური ინვარიანტი აღინიშნება $Y$-ით, ხოლო სტანდარტულ სკალარულ-ტენზორულ ლიტერატურაში ხშირად გამოიყენება $X$. მოცემული სტატიის $(+---)$ სიგნატურაში მათი კავშირია $Y=-2X$. ამ ასახვის შედეგად, მინიმალური ფაზური ნაწილი $G_2(X)$ შემდეგ ფორმას იღებს. აქ $c_Y$ და $c_{Y2}$ აღნიშნავს თავდაპირველი $Y$-სქემის კოეფიციენტებს; $X$-სქემაში გადასვლა მხოლოდ $Y=-2X$ ჩანაცვლებით ხდება:*

```text
G2(X) = -2 c_Y X + 4 c_Y2 X^2,
G3 = 0,
G4 = M_Pl^2/2,
G5 = 0.
```

*აღნიშნულ მინიმალურ ხიდში $G_4$ მუდმივია და $G_5=0$, რის გამოც ტენზორული სიჩქარის სიჭარბე $\alpha_T$ ნულდება. ეს პირდაპირ აკმაყოფილებს გრავიტაციული ტალღების გავრცელების სიჩქარის კრიტერიუმს, რადგან თანამედროვე დაკვირვებები მკაცრად ზღუდავს ტენზორული ტალღის სიჩქარის სინათლის სიჩქარისგან გადახრას [4,5]. ტალღური სექტორის სრული ფენომენოლოგია დამოუკიდებლად მოიცავს დისპერსიას, დამატებით პოლარიზაციებს, ამპლიტუდის ევოლუციასა და ძლიერი ველის ტალღურ ფორმებს.*

*სივრცული მედიუმის $I_k$ სექტორი სუფთა ჰორნდესკის ფუნქციებში არ დაიყვანება. იგი წარმოადგენს მყარი სხეულის ეფექტური ველის თეორიის (solid-EFT) ტიპის სივრცულ სექტორს, რომელიც ეფექტურ წყაროში დამოუკიდებელ სივრცულ სტრესს განაპირობებს [6,7,25,26]. შესაბამისად, მინიმალური სტრუქტურა შემდეგნაირად იწერება:*

```text
(RefG)_min = Einstein-Hilbert + F_phase(Y) + F_solid(I1,I2,I3) + c_YI1 Y I1.
```

*ამ მინიმალურ ფორმაში, RefG-ის სტრუქტურა ოთხი ნაწილის ერთიან განშტოებათა სისტემაში გაერთიანებას გულისხმობს. ესენია: აინშტაინ-ჰილბერტის ბირთვი, ფაზური სექტორი $F_{\rm phase}(Y)$, solid-EFT სივრცული სექტორი და ფაზა-სივრცის $Y I_1$ შეწყვილება. ჰორნდესკის/EFT ხიდში იგივე ფაზური სექტორი ზემოთ მოცემულ $G_2(X)$ ფორმაში გადაიწერება. ამ კონსტრუქციაში მინიმალური იზოტროპული 2PN დახურვა ცალკე დიაგნოსტიკური ტოტია და არ განსაზღვრავს კალიბრირებული `S=6` განშტოების მზის პროგნოზს.*

*მოდიფიცირებული ნიუტონის დინამიკის (MOND) ტიპის მოდელებთან განსხვავება არქიტექტურული ხასიათისაა [8]. MOND-ის ფენომენოლოგიის ფორმულირება, როგორც წესი, აჩქარების კანონის ან ინტერპოლაციის ფუნქციის დონიდან იწყება. ამის საპირისპიროდ, RefG-ის ამოსავალი წერტილი ფუძე-მედიუმის პოსტულატი, ინვარიანტები და მოქმედებაა. ამ ნაშრომში MOND-ის სფერული სუსტი ველის ბირთვი მიიღება RefG-ის სტრესიდან, ფაზური კოჰერენტობის მასშტაბიდან და ვარიაციული ვორტექსული დატვირთვიდან; დისკური curl-შესწორებები და სრული გალაქტიკური ალბათობითი მორგება შემდგომი ფენომენოლოგიური ფენაა.*

*ანალოგიური მედიუმის, სუპერსოლიდური და სტრუქტურირებული ვაკუუმის ფორმალიზმებთან კავშირი გამოყენებულია როგორც სტრუქტურული ორიენტირი [6,7]. წინამდებარე ნაშრომი ადგენს მინიმალური ფაზა-სივრცული ტრანკაციის ძირითად შედეგებს და მათ დაკვირვებით კრიტერიუმებს.*

## *4. ფუძე-მედიუმის პოსტულატი*

*პოსტულატი. RefG-ში შემოყვანილია ეფექტური ფუძე-მედიუმი, რომელიც არ განიხილება როგორც დამოუკიდებელი, დაკვირვებადი მატერია. იგი განისაზღვრება იმ პასუხით, რომელსაც მატერია, ფაზური აქტივობა ან გლობალური ფონური მდგომარეობა გრავიტაციულ სექტორში წარმოქმნის.*

*მოცემული პოსტულატის ფორმალური როლი მოქმედების სტრუქტურის განსაზღვრაა. ფუძე-მედიუმის კონცეფცია მიუთითებს, რომ დამატებითი გრავიტაციული პასუხი უნდა ფორმულირდეს ფაზური და სივრცული ცვლადების, მათგან აგებული ინვარიანტებისა და კოვარიანტული ვარიაციის გამოყენებით.*

*ფაზური ველი აღინიშნება $\Phi$ სიმბოლოთი და აღწერს ფონურ საათს ან ფაზურ სექტორს. სივრცული მედიუმის ველები აღინიშნება $\phi^A$-თი, სადაც $A=1,2,3$, და ისინი ფუძის სივრცულ სტრუქტურას აღწერენ. აღნიშნული ორი ტიპის ველი ერთიანდება ერთ ეფექტურ მოქმედებაში, რომელშიც დროითი და სივრცული პასუხი ერთიან კონსტრუქციაშია ინტეგრირებული.*

*თეორიის გაზომვადი შინაარსი ვლინდება არა ფუძე-მედიუმის თავისუფალ მდგომარეობაში, არამედ მის გრავიტაციულ კვალში: დროის სკალის ცვლილებაში, სივრცული სტრესის პასუხში, კოსმოლოგიურ ფონურ წნევაში, ტალღის გავრცელების სექტორსა და სუსტი ველის კოეფიციენტებში. შესაბამისად, თითოეული ასეთი კვალი შემდგომ სექციებში შესაბამის დაკვირვებით კრიტერიუმს უკავშირდება.*

## *5. წნევა-ენერგიის ბალანსი და რეფრაქციული პასუხი*

*RefG-ის რეფრაქციული აღწერა ფუძე-მედიუმის ლოკალურ წნევით პასუხს ეფუძნება. მატერია ან ფაზა-სივრცული აქტივობა ცვლის ეფექტურ წნევით-ენერგეტიკულ განაწილებას, რომელშიც ფაზური, ელასტიური და შეწყვილებული წვლილები ერთიანდება. სტაციონარულ ან კვაზისტაციონარულ რეჟიმში აღნიშნული ბალანსი კომპაქტური სახით შემდეგნაირად ჩაიწერება:*

```text
Q_RefG = Pi_eff + E_phase + E_elastic + E_int.

delta Q_RefG = 0,
delta Pi_eff + delta E_phase + delta E_elastic + delta E_int = 0.
```

*აქ `Pi_eff` დამოუკიდებელ მატერიას არ აღნიშნავს. იგი არის ეფექტური წყაროს სკალარული წნევითი ნაწილი, ხოლო `E_phase`, `E_elastic` და `E_int` აღწერს იმავე წყაროს ფაზურ, ელასტიურ და შეწყვილებულ ენერგეტიკულ წვლილებს. ლოკალურ წყაროსთან ამ წვლილების ზრდა ბალანსის პირობაში წნევითი ნაწილის შემცირებით კომპენსირდება:*

```text
delta E_phase + delta E_elastic + delta E_int > 0,
delta Pi_eff < 0.
```

*ეფექტური წყარო მეტრიკულ პასუხში ერთ უნივერსალურ ცვლადად იკრიბება. სუსტი სტატიკური რეჟიმისთვის ეს ცვლადი განისაზღვრება შემდეგი სახით:*

```text
g_tt = exp(-2 h_eff),
n_eff = exp(h_eff).
```

*მატერიის მინიმალური მეტრიკული ბმა ამ ფორმაში იძლევა უნივერსალურ სუსტ პოტენციალს `V_eff/m=-c^2 h_eff`. შედეგად ტესტ-მატერიის აჩქარება რეფრაქციული ინდექსის გრადიენტით გამოისახება:*

```text
a_r = c^2 d log(n_eff)/dr = c^2 h_eff'.
```

*წყარო მოქმედებიდან მოდის. სფერულ SO(3)-კოვარიანტულ დეფორმაციაში `B^{AB}`-ის საკუთარი მნიშვნელობებია `lambda_r=f'(r)^2/A(r)` და `lambda_t=f(r)^2/C(r)`. RefG მოქმედების ვარიაცია იძლევა რადიალურ და ტანგენციურ წნევებს `p_rad`, `p_tan`, ხოლო ანიზოტროპიული წყარო არის*

```text
Delta_p = p_tan - p_rad.
```

*იზოტროპულ ზღვარში `Delta_p=0`, ხოლო რადიალურ-ტანგენციური დეფორმაციის დროს `Delta_p` გენერირდება იმავე `L_RefG` მოქმედებიდან. ამიტომ რეფრაქციული წყარო არ არის დამატებული ძალა და არ არის ახალი მატერია; იგი არის ფუძე-მედიუმის აქტიური სტრესი.*

*სუსტი ანიზოტროპიული წონასწორობის პროექცია იძლევა შემდეგ საერთო კავშირს:*

```text
p_rad' + rho_eff Phi_N' - 2 Delta_p/r = 0,
Phi_N = -c^2 h_eff,
h_eff' = (p_rad' - 2 Delta_p/r)/(c^2 rho_eff).
```

*ამ ერთი ფორმულიდან მიიღება ორი ზღვრული რეჟიმი. ლოკალურ წყაროსთან `Delta_p=0`. `p10`-ის სტატიკურ-სფერული პირველი რიგის განტოლებებში დამოუკიდებელი რადიალური წევრები ადგენს `a1=1` პირობას, ანუ `A B=1+O(U^2)`. ამავე არხში Bernoulli-რადიალური პასუხი იძლევა `h_eff=GM/(c^2 r)` პროფილს და ნიუტონის კანონს. წყაროს ცენტრალური ქცევა რეგულარულია: ექსპონენციალური განზავების წევრი Bernoulli-წნევას ცენტრში ნულამდე აქრობს, მისი მაქსიმუმი მდებარეობს `r_s/4`-ზე, ხოლო რადიალური ინტეგრალი სასრულია. გარე `1/r` კოეფიციენტი ფიქსირდება ასიმპტოტური გრავიტაციული მუხტით: `phi=-mu/r` შემთხვევაში `mu=2GM/c^2`, ამიტომ ნიუტონის ნორმალიზაცია დამატებით მორგებას არ საჭიროებს. კოჰერენტულ ვორტექსულ რეჟიმში `p_rad'` წამყვან რიგში ქრება, ხოლო `Delta_p` p01-ის ანიზოტროპიული დეფორმაციის განშტოება ხდება. მუდმივი პლატო*

*კვადრატული Bernoulli-წნევა და ხაზოვანი TOV წყარო ერთმანეთს არ ეწინააღმდეგება. TOV-ის განტოლებაში ძალის წყაროდ შედის არა თვითონ `Pi_B`, არამედ ხაზოვანი კომბინაცია `S_h=p_rad'-2 Delta_p/r`. p10 ამ კომბინაციაში შედის `Pi_B'` წევრით, ხოლო ვორტექსული არხი შედის `-2 Delta_p/r` წევრით. ამიტომ Bernoulli-ის კვადრატულობა წნევითი ფუნქციის თვისებაა, ხოლო დინამიკურ წყაროს მისი რადიალური წარმოებული ქმნის.*

```text
Delta_p = rho_eff sqrt(G M a0)/2
```

*იძლევა ლოგარითმულ `h_eff`-ს, deep-MOND აჩქარებას და BTFR-ს.*

*აჩქარების მასშტაბი ფაზური კოჰერენტობიდან მოდის. კოსმოლოგიური დეფაზირების სიჩქარე იძლევა `k_H=H/c`. ერთი კოჰერენტული უჯრედი სრული ფაზური ციკლია, ამიტომ*

```text
k_H lambda_H = 2 pi,
lambda_H = 2 pi c/H,
a0 = c^2/lambda_H = cH/(2 pi).
```

*აქ `2 pi` არ არის ფენომენოლოგიური მორგება; ეს არის სრული ფაზური ციკლის ნორმალიზაცია. ვორტექსული დატვირთვის ვარიაციული პოტენციალი*

```text
W(g_v; g_N) = g_v^3/3 + g_N g_v^2/2 - a0 g_N g_v
```

*სტაციონარულად იძლევა*

```text
g_v/g_N = a0/g,
g = g_N + g_v.
```

*აქედან მიიღება `mu(x)=x/(1+x)`: ძლიერი ველისას ვორტექსული არხი ითრგუნება და რჩება ნიუტონის რეჟიმი, ხოლო სუსტი ველისას მიიღება deep-MOND. უსასრულო ლოგარითმული კუდი იკვეთება კოჰერენტობის რადიუსზე*

```text
R_coh = c^2/a0 = 2 pi c/H.
```

*გლუვი ჩამხშობი ფუნქცია `S(r)=1/(1+(r/R_coh)^2)` შიგნით ინარჩუნებს MOND-ის პლატოს, გარეთ კი აჩქარებას `r^-3` რიგამდე აქრობს. ამრიგად სუსტი ველის რეფრაქციული ჯაჭვი შემდეგი თანმიმდევრობით ყალიბდება:*

```text
p01 მოქმედების სტრესი
-> p10 პირველი რიგის ბიკონფორმული არჩევა
-> p10 ნიუტონის რადიალური პასუხი
-> p10 Bernoulli ბირთვის რეგულარული ქცევა
-> ასიმპტოტური მუხტის ნორმალიზაცია
-> აქტიური სტრესის წყაროს სქემა
-> p01 MOND დეფორმაციული პლატო
-> a0 ფაზური კოჰერენტობიდან
-> ვარიაციული ვორტექსული დატვირთვა
-> კოჰერენტობის სასრული მოჭრის რადიუსი
-> h_eff
-> n_eff
-> რეფრაქციული ძალა.
```

*ამ შედეგის მოქმედების არე არის სუსტი, სტატიკური ან გასაშუალოებული რეჟიმი. ძლიერი ველი, დისკური curl-შესწორებები და სრულად არასფერული PDE ამოხსნები ცალკე გამოთვლით გაგრძელებას მოითხოვს.*

## *6. ინვარიანტები, სიმეტრიები და ნიშნის შეთანხმება*

*მეტრიკის სიგნატურაა `(+---)`. წინამდებარე სტატიაში გამოყენებული კონვენციები შეჯამებულია შემდეგ ცხრილში:*

| *ობიექტი*                              | *კონვენცია*                                                                                                                                                       |
| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| *მეტრიკა*                              | *`(+---)`*                                                                                                                                                               |
| *რიმანის ტენზორი*               | *`R^rho_{ sigma mu nu}=d_mu Gamma^rho_{nu sigma}-d_nu Gamma^rho_{mu sigma}+Gamma^rho_{mu lambda} Gamma^lambda_{nu sigma}-Gamma^rho_{nu lambda} Gamma^lambda_{mu sigma}`* |
| *რიჩის ტენზორი*                   | *`R_{mu nu}=R^rho_{ mu rho nu}`*                                                                                                                                         |
| *აინშტაინის ტენზორი*         | *`G_{mu nu}=R_{mu nu}-1/2 g_{mu nu} R`*                                                                                                                                  |
| *გრავიტაციული მოქმედება* | *`S_g=integral sqrt(-g) (M_Pl^2/2) R d^4x`*                                                                                                                              |
| *ველის განტოლება*               | *`M_Pl^2 G_{mu nu}=T^{m}_{mu nu}+T^{RefG}_{mu nu}`*                                                                                                                      |
| *RefG ეფექტური წყარო*            | *`T^{RefG}_{mu nu}=2 dL_{RefG}/dg^{mu nu}-g_{mu nu} L_{RefG}`*                                                                                                           |
| *ფაზური ინვარიანტი*           | *`Y=g^{mu nu} d_mu Phi d_nu Phi=-2X`*                                                                                                                                    |

*აღნიშნული ცხრილის მიზანია უზრუნველყოს სიმკვრივის, წნევის, კინეტიკური ნიშნისა და ჰორნდესკის თარგმანის ნიშნების ერთიანი სქემის ფარგლებში მოქცევა. შემდგომი ფორმულები მკაცრად მიჰყვება ამ კონვენციას.*

*სტრეს-ტენზორის ზემოთ მოცემული ფორმა გამოიყენება დიაგონალურ ან უნიკალურ მეტრიკულ ცვლადებზე. არადიაგონალური სიმეტრიული ცვლადების შემთხვევაში `g^{mu nu}=g^{nu mu}` ერთი ცვლადი მატრიცის ორ ელემენტს წარმოადგენს, ამიტომ `mu != nu` კომპონენტისთვის გამოიყენება `T_{mu nu}=dL/dg^{mu nu}-g_{mu nu}L`.*

*რაც შეეხება ერთეულებს, სტატიის ძირითადი ფორმულები ბუნებრივ ერთეულებში (`c=hbar=1`) იწერება. ეფექტური ველის თეორიის (EFT) პრაქტიკული ფორმულირება შემდეგნაირია:*

```text
L_{RefG} = M_*^4 * F(Y, I1, I2, I3),
```

*სადაც `F`-ის კოეფიციენტები განზომილების არმქონე (dimensionless) ნორმალიზაციით არის წარმოდგენილი. ველებისათვის განსხვავებული კანონიკური განზომილების მინიჭების შემთხვევაში, კოეფიციენტები (`c_Y`, `c_Y2`, `c_I1`, ...) შესაბამის მაკომპენსირებელ განზომილებებს იღებენ. სტატიაში მოყვანილი ყველა პარამეტრული მაგალითი განზომილების არმქონე `F`-ის შიგნით განიხილება; დაკვირვებითი კალიბრაცია, მაგალითად `rho_DE`, საერთო ენერგეტიკულ მასშტაბს `M_*^4` აფიქსირებს.*

*ფაზური ინვარიანტი განიმარტება როგორც:*

```text
Y = g^{mu nu} d_mu Phi d_nu Phi.
```

*სივრცული მედიუმის მატრიცა კი მოიცემა ფორმულით:*

```text
B^{AB} = -g^{mu nu} d_mu phi^A d_nu phi^B.
```

*აქ `phi^A`, სადაც `A=1,2,3`, არ წარმოადგენს ფიქსირებულ კოორდინატს. ეს არის სამი სკალარული ველი, რომელიც ფუძე-მედიუმის თანმავალ ნიშნულებს აღწერს. სივრცე-დროის დიფეომორფიზმის მიმართ `phi^A` სკალარივით გარდაიქმნება, ხოლო `B^{AB}` სივრცე-დროითი ინდექსების მეტრიკით შეკუმშვის შედეგად მიიღება. შესაბამისად, მოქმედება, რომელიც `Y`, `I1`, `I2`, `I3` სკალარებით იწერება, კოვარიანტულია და წინასწარ დაფიქსირებულ კოორდინატულ ტენზორს არ შეიცავს.*

*ერთგვაროვანი ფონი ხშირად ერთეულოვან ყალიბში (unitary gauge) იწერება:*

```text
phi^A = x^A,
B^{AB} = delta^{AB}.
```

*FLRW ფონზე, სადაც `ds^2 = dt^2 - a(t)^2 dx^i dx^i`, აღნიშნული ერთეულოვანი ყალიბი იძლევა:*

```text
B^{AB} = delta^{AB}/a^2,
I1 = 3/a^2,
I2 = 3/a^4,
I3 = 1/a^6.
```

*ეს ჩანაწერი სპონტანურად არჩეულ ფონურ ათვლის სისტემას აღწერს: კონკრეტული ფიზიკური ფონი მედიუმის უძრავ ჩარჩოს ირჩევს. სიმეტრიის დარღვევა სპონტანურია, მსგავსად მყარი სხეულების ან სუპერსოლიდების ეფექტური თეორიისა [6,7]. მიუხედავად მოქმედების კოვარიანტობისა, ფონური ამოხსნა, ლორენც-ინვარიანტული ვაკუუმის ნაცვლად, მედიუმის ჩარჩოს ანიჭებს უპირატესობას. ერთეულოვანი ყალიბის მიღმა იდენტური ფიზიკა `phi^A` ველების ფლუქტუაციებით, კერძოდ კი, გოლდსტოუნის/შტუკელბერგის ფორმალიზმით იწერება.*

*მატრიცაში `B^{AB}` მინუს ნიშანი ისეა შერჩეული, რომ ერთგვაროვან სივრცულ ფონზე სივრცული მედიუმის მატრიცამ დადებითი ერთეულოვანი ფორმა მიიღოს. მისი მეშვეობით სამი ძირითადი ინვარიანტი განისაზღვრება:*

```text
I1 = tr(B),
I2 = 1/2 * (I1^2 - tr(B^2)),
I3 = det(B).
```

*ეს სამი დამოუკიდებელი, სიმეტრიული ინვარიანტი საკმარისია მინიმალური პოლინომიალური სივრცული სექტორის ფორმულირებისთვის. `I1` წარმოადგენს პირველ კვალს, `I2` — მეორე სიმეტრიულ კომბინაციას, ხოლო `I3` მოცულობით პასუხს განსაზღვრავს.*

*ნიშანთა შეთანხმებას გადამწყვეტი მნიშვნელობა ენიჭება ფაზურ სექტორში. ჰორნდესკისა და ბნელი ენერგიის ეფექტური ველის სტანდარტულ ფორმალიზმში ხშირად გამოიყენება შემდეგი სიდიდე:*

```text
X = -1/2 g^{mu nu} d_mu Phi d_nu Phi.
```

*რაც უშუალოდ განაპირობებს კავშირს:*

```text
Y = -2X.
```

*`(+---)` სიგნატურის პირობებში, დროით ერთგვაროვან ფონზე `Y = dot(Phi)^2 > 0`, ხოლო `X`-ის ნიშნის ზემოაღნიშნული კონვენციით `X = -dot(Phi)^2/2 < 0`. შესაბამისად, `Y = -2X` წარმოადგენს ნოტაციურ თარგმანს ამ კონკრეტულ სიგნატურაში.*

*იმ შემთხვევაში, თუ ფორმულები `(-+++)` სიგნატურაში გადაიწერება, `Y`, `B^{AB}` და `X`-სქემის ნიშნების ხელახალი ტრანსლაცია გახდება აუცილებელი. წინამდებარე სტატიაში ყველა კოეფიციენტური პირობა, მათ შორის კინეტიკური სტაბილურობის არე და `Y = -2X` ხიდი, ფიქსირებულია `(+---)` სქემაში.*

*თუ RefG-ის ლაგრანჟიანი შეიცავს წევრებს `c_Y Y + c_Y2 Y^2`, მაშინ `X`-სქემაში შესაბამისი ფორმა ასეთია:*

```text
c_X = -2 c_Y^(Y),
c_X2 = 4 c_Y2^(Y).
```

*აღნიშნული ხიდის დაფიქსირება აუცილებელია, ვინაიდან ერთი და იგივე ფიზიკური პირობა `Y`-სქემასა და `X`-სქემაში სხვადასხვა ნიშნით აისახება. კინეტიკური ნიშნების არევის საშიშროება სწორედ აქ იჩენს თავს: თუ გამოყენებული სქემა მკაფიოდ არ არის მითითებული, შესაძლოა `c_Y > 0` და `c_X < 0` წინააღმდეგობად აღვიქვათ, მაშინ როცა ისინი ერთი და იმავე თარგმანის შედეგს წარმოადგენენ. ამ სტატიაში ყველა ფაზური ფორმულა უპირველესად `Y`-სქემაში იწერება, ხოლო ჰორნდესკის ხიდის მეშვეობით მათი `X`-სქემაში ტრანსლაცია დამოუკიდებლად ხორციელდება.*

## *7. ეფექტური მოქმედება*

*მინიმალური პოლინომიალური RefG ლაგრანჟიანი იწერება შემდეგი სახით:*

```text
L_{RefG} =
    c_Y Y
  + c_Y2 Y^2
  + c_I1 I1
  + c_I1sq I1^2
  + c_I2 I2
  + c_I3 I3
  + c_YI1 Y I1.
```

*ამ ფორმის ალგებრული საფუძველი ასეთია. ფუძე-მედიუმის ფორმალურ ენაში გვაქვს ერთი ფაზური სკალარი `Y` და სამი სივრცული მედიუმის სკალარი `I1`, `I2`, `I3`. ამ სტატიაში არ მტკიცდება ყველა სიმეტრიით დაშვებული ოპერატორის სრული კლასიფიკაცია. არჩეულია მინიმალური ტრანკაცია, რომელიც შეიცავს ფაზურ კინეტიკას, პირველ ფაზურ არაწრფივობას, solid-EFT-ის წამყვან სივრცულ ინვარიანტებს და უმარტივეს ფაზა-სივრცულ შეწყვილებას:*

```text
{ Y, Y^2, I1, I1^2, I2, I3, Y I1 }.
```

*ამ ბაზისის ზოგადი წრფივი კომბინაცია ზუსტად იძლევა ზემოთ დაწერილ `L_{RefG}`-ს. აქ არ ხდება კოეფიციენტების მიკროსკოპული წარმოშობის გამოცხადება და არც იმის მტკიცება, რომ სხვა დაშვებული ოპერატორები არ არსებობს. მტკიცება უფრო შეზღუდულია: ამ არჩეული მინიმალური ტრანკაციის შიგნით ყველა შემდგომი გამოთვლა ერთსა და იმავე ლაგრანჟიანს ეყრდნობა.*

*ამ მინიმალური ბაზისის რიგობრივი დათვლა ასეთია. დაშვებულია შიდა ფაზური წანაცვლება:*

```text
Phi -> Phi + const,
```

*და სივრცული მედიუმის თანმხლები წანაცვლება:*

```text
phi^A -> phi^A + c^A.
```

*სივრცულ ინდექსებზე მოქმედებს შიდა `SO(3)` სიმეტრია, ამიტომ ლაგრანჟიანში `B^{AB}` შედის სიმეტრიული ინვარიანტებით. ამ სტატიის ოპერატორული დათვლის წესი არის EFT ტრანკაციის მინიმალური არჩევანი და არა სრული CCWZ კლასიფიკაცია [24-26]. `Y`, `I1`, `I2`, `I3` ითვლება წამყვან ინვარიანტებად; `Y^2` და `I1^2` ინარჩუნებს პირველ არაწრფივ თვითშესწორებას იმ ორ არხში, რომლებიც უშუალოდ შედის ფაზურ საათსა და მოცულობით ელასტიურ პასუხში; `Y I1` კი ინარჩუნებს პირველ ჯვარედინ წევრს ფაზურ და სივრცულ სექტორებს შორის. იმავე სიმეტრიებით დაშვებული სხვა წევრები, მაგალითად `Y I2`, `Y I3`, `I1 I2`, `I1 I3`, `I2^2`, `I2 I3`, `I3^2`, `Y^3`, `Y^2 I1`, `I1^3`, `R Y` ან `R_{mu nu} d^mu Phi d^nu Phi`, ამ სტატიის მინიმალურ ტრანკაციაში არ შედის და გაფართოებულ EFT-ს მიეკუთვნება.*

*ჭრის მასშტაბს აღვნიშნავთ `Lambda_EFT`-ით. პრაქტიკული ნორმალიზაცია არის `L = M_*^4 F`, სადაც ამ სტატიის `c_i` კოეფიციენტები განზომილების არმქონეა, ხოლო ფიზიკური სიმკვრივის კოეფიციენტები იღებს `M_*^4` მასშტაბს. დაბალენერგიულ სექტორში იგულისხმება `Lambda_EFT ~ M_*`; მის ზემოთ ჩნდება გაფართოებული ოპერატორები თავისი დამოუკიდებელი კოეფიციენტებით. ამ მინიმალურ ხიდში `G3=0` და `G5=0` არის ჭრის მასშტაბის ქვემოთ მოქმედი ტრანკაციის არჩევანი. სიმრუდესთან დაკავშირებული წევრები, როგორიცაა `R Y` ან `R_{mu nu} partial^mu Phi partial^nu Phi`, გაფართოებულ EFT-ს მიეკუთვნება და ნაგულისხმევად ჩართულად არ ითვლება.*

*ეს არჩევანი განსაზღვრავს ამ სტატიის მინიმალურ მოდელს. თუ დაკვირვებითი ან სტაბილურობის კრიტერიუმი მოითხოვს `Y I2`-ს, `I1 I2`-ს ან სხვა დაშვებული წევრის ჩართვას, მაშინ მინიმალური RefG ტრანკაცია კონტროლირებადი EFT წესით უნდა გაფართოვდეს. ასეთ შემთხვევაში გაფართოების საჭიროება მოდის მინიმალური ტრანკაციის საზღვრიდან და არა მოქმედების შეცვლილი ინტერპრეტაციიდან.*

*პირველი ასეთი კონტროლირებადი გაფართოება, რომელიც ამ სტატიაში სხვადასხვა განშტოების შესაკავშირებლად გამოიყენება, ეფუძნება კომბინაციას:*

```text
S = Y + 2 I1 - I3.
```

*შევსების ლაგრანჟიანის ფონური ნაწილი იწერება:*

```text
L_S = lambda_S (S - 6)^2 - rho_0.
```

*რიცხვი `6` მოდის ერთეულოვანი ფონიდან:*

```text
Y_0 = 1,
I1_0 = 3,
I3_0 = 1,
S_0 = Y_0 + 2 I1_0 - I3_0 = 6.
```

*ალგებრული გაშლა ზუსტად არის:*

```text
(S - 6)^2 =
    Y^2 + 4 Y I1 - 2 Y I3
  + 4 I1^2 - 4 I1 I3 + I3^2
  - 12 Y - 24 I1 + 12 I3 + 36.
```

*ამ გაშლაში `Y I3`, `I1 I3` და `I3^2` არის ის გაფართოებული ოპერატორები, რომლებიც შვიდწევრიან მინიმალურ ბაზისში არ შედის. სწორედ ამიტომ `lambda_S (S - 6)^2` არ არის მინიმალური ბირთვის გადარქმევა; იგი არის პირველი გამოთვლადი შევსება, რომელიც მინიმალურ ბირთვს კონტროლირებადად აფართოებს.*

*ამ გაფართოების საჭიროება მინიმალური ბირთვის no-go ლემიდან მოდის. ზუსტი ΛCDM ფონური დახურვა მინიმალურ ნულოვანი-დენის ბალანსში მოითხოვს `c_I3=0`. მეორე მხრივ, Solar 1PN ფართობის-რადიუსის stress-free განშტოება იძლევა:*

```text
c_I3 = 8 c_Y2 + 4 c_YI1.
```

*ორივე პირობის ერთად მოთხოვნა აყენებს `c_YI1=-2 c_Y2`. ამ ჩასმით 1PN განშტოებაზე მიიღება `c_Y=0`, `c_I1=0`, `c_I2=-4 c_Y2`, ხოლო ზუსტი ΛCDM ბალანსი ამავე დროს ითხოვს `c_I2=0`. შედეგად რჩება `c_Y2=0`, რაც ეწინააღმდეგება არატრივიალური no-ghost ფანჯრის აუცილებელ პირობას `c_Y2>0`. ამიტომ მუდმივ-კოეფიციენტიანი მინიმალური ბირთვი ვერ ხურავს ერთდროულად ზუსტ ΛCDM ფონსა და Solar 1PN-ს სტაბილურ არატრივიალურ სექტორში. `S=6` შევსება ამ ლემის შემდეგ იძულებითი გაფართოებაა, არა თავისუფალი მორგება.*

*ამ წევრის მინიმუმი არის `S=6`. იგი იგივე `Y,I_k` ინვარიანტებით დაწერილი EFT წევრია. ფიზიკურად `lambda_S (S - 6)^2` არის მასური წევრის მსგავსი ფსკერი ეფექტური `delta S` ცვლადისთვის: `lambda_S` განსაზღვრავს, რამდენად მკაცრად იკეტება განშტოება, ხოლო `lambda_S -> infinity` ლიმიტში იგი მოქმედებს როგორც შეზღუდვა `S=6`. ამიტომ ქვემოთ გამოყენებული საერთო კოსმოლოგიურ-მზის განშტოება მინიმალური ბირთვის პირველი შევსებაა.*

*მყარი სექტორის კინეტიკური საზღვრის გასამკაცრებლად სისტემას ემატება ფონზე ნულოვანი კინეტიკური ინვარიანტი `Z`:*

```text
Z = delta_AB (u^mu partial_mu phi^A)(u^nu partial_nu phi^B),
u_mu = partial_mu Phi / sqrt(Y),
L_Z = c_Z Z.
```

*ეს განსაზღვრება ლოკალურია იმ განშტოებაზე, სადაც `Y>0`, რადგან `u_mu` შეიცავს `sqrt(Y)`-ს. `S=6` FLRW განშტოებაზე მინიმალური მნიშვნელობაა `Y_min = 6 - 4 sqrt(2) > 0`, ამიტომ ეს პირობა სრულდება. ძლიერი ველის ან არანულოვანი აქტიური წყაროს მქონე განშტოებები, სადაც `Y` შეიძლება ნულს მიუახლოვდეს, ცალკე გადამოწმებას მოითხოვს.*

*ერთგვაროვან FLRW ფონზე და სტატიკურ მზის ფონზე `Z=0`, ამიტომ იგი ფონურ ΛCDM ალგებრასა და Solar 1PN სტრესულ დახურვას არ ცვლის. ფლუქტუაციების დონეზე კი იგი მყარ სექტორს დადებით კინეტიკურ წევრს ანიჭებს.*

*ლოკალურ ნორმალიზებულ ფონზე `Phi=t`, `phi^A=x^A` და სტატიის შტუკელბერგის კონვენციით `phi^A=x^A+pi^A`, შევსების ხაზოვანი და კვადრატული ნაწილები ინვარიანტებიდან პირდაპირ იღებს სახეს:*

```text
delta Y  = 2 dot chi,
delta I1 = 2 div pi,
delta I3 = 2 div pi,
delta S  = 2 (dot chi + div pi),
Z = (dot pi_i - partial_i chi)^2.
```

*სკალარულ-გრძივ სიმბოლოში ვიყენებთ გრძივ ამპლიტუდას წესით `div pi -> -k pi_L`. ამიტომ იგივე ინვარიანტული ფორმულა principal-symbol ენაში იკითხება ასე:*

```text
delta S -> 2 (omega chi - k pi_L),
Z -> (omega pi_L - k chi)^2.
```

*თუ გამოიყენება საპირისპირო წანაცვლების კონვენცია `phi^A=x^A-pi^A`, საჭიროა `pi -> -pi` ჩანაცვლება ყველგან, მათ შორის `delta S`-ში, `Z`-ში და გრძივ ფურიე-ამპლიტუდაში. ქვემოთ ლოკალური შეშფოთებების principal-symbol შემოწმება სწორედ ამ თანმიმდევრულ კონვენციას იყენებს.*

*სრული ეფექტური მოქმედებაა:*

```text
S = integral sqrt(-g) [ (M_Pl^2/2) R + L_{RefG} + L_m ] d^4x.
```

*აქ `L_m` მატერიის სექტორია. ამ სტატიაში მატერიის სექტორი მეტრიკასთან მინიმალურად დაკავშირებულად ითვლება. ეს არჩევანი ინარჩუნებს სტანდარტულ გეოდეზიურ აღწერას და საშუალებას იძლევა RefG-ის დამატებითი ფიზიკა წავიკითხოთ როგორც ეფექტური ფუძე-მედიუმის სტრესი და არა როგორც მატერიის სექტორის ხელოვნური მოდიფიკაცია.*

*ლაგრანჟიანის თითოეულ ტერმინს აქვს კონკრეტული როლი. `c_Y Y` არის ფაზური კინეტიკური წევრი. `c_Y2 Y^2` არის ფაზური არაწრფივი შესწორება. `c_I1 I1`, `c_I1sq I1^2`, `c_I2 I2`, `c_I3 I3` ქმნის სივრცული მედიუმის სექტორს. `c_YI1 Y I1` არის ფაზა-სივრცული შეწყვილება. ეს ბოლო წევრი მნიშვნელოვანია, რადგან სწორედ ის აკავშირებს ფონურ საათს სივრცული მედიუმის პასუხთან.*

*`Y`-სექტორი ჰორნდესკის მინიმალურ ენაში გადადის შემდეგნაირად:*

```text
G2(X) = -2 c_Y X + 4 c_Y2 X^2,
G3 = 0,
G4 = M_Pl^2/2,
G5 = 0.
```

*აქ `c_Y` და `c_Y2` არის `Y`-სქემის კოეფიციენტები, ხოლო `X`-სქემაში გადასვლა იყენებს მე-6 სექციაში დაფიქსირებულ კავშირს `Y=-2X`. ამიტომ ფაზური ნაწილი არის `G2` ტიპის სკალარული სექტორი, ხოლო `I_k` ნაწილი რჩება დამატებით მყარი მედიუმის სტრესად. ამ გაყოფას ორი უშუალო შედეგი აქვს. პირველი: მინიმალურ ჰორნდესკის მხარეს ტენზორული სიჩქარის კრიტერიუმი იძლევა `alpha_T=0`-ს. მეორე: ამ მინიმალურ აღწერაში რჩება დამოუკიდებელი ელასტიური წყაროც.*

*RefG ეფექტური წყარო განისაზღვრება მე-6 სექციაში გამოცხადებული ნიშნით. დიაგონალური ან უნიკალური მეტრიკული ცვლადებისათვის გამოიყენება:*

```text
T_{mu nu}^{RefG} = 2 dL_{RefG}/dg^{mu nu} - g_{mu nu} L_{RefG}.
```

*არადიაგონალური სიმეტრიული ცვლადების ტექნიკური გამონაკლისი მე-6 სექციაშია დაფიქსირებული და აქ აღარ მეორდება. ზემოთ მოცემული ვარიაციული განსაზღვრებიდან მიიღება ფონური სიმკვრივე, იზოტროპული წნევა და სუსტი ველის სტრესის წევრები. სტატიის შემდგომი ფორმულები სწორედ ამ განსაზღვრებას ეყრდნობა.*

*ამიტომ პირველი დახურული შედეგი არის არჩეული შვიდწევრიანი ტრანკაციის შიდა თანმიმდევრულობა. ამ სივრცეში ფაზური, სივრცული მედიუმის და ფაზა-სივრცული პასუხები ერთიანი პრინციპით იწერება, ხოლო შემდგომი გამოთვლები ამავე `L_{RefG}`-ს ეყრდნობა.*

***შედეგი 1.*** *არჩეული მინიმალური ტრანკაციისათვის RefG იძლევა პოლინომიალურ ეფექტურ მოქმედებას. ფაზური `Y`-სექტორი მინიმალურ ჰორნდესკის ხიდში გადადის `G2(X)` ფორმაში, ხოლო სივრცული მედიუმის `I_k` სექტორი რჩება დამოუკიდებელ solid-EFT ტიპის ეფექტურ სტრესად. ეს არის მინიმალური ანზაცი; სრული სიმეტრიული EFT ბაზისის აგება დამოუკიდებელ გაფართოებას მიეკუთვნება.*

## *8. ვარიაციული სტრუქტურა*

*მოქმედების ფორმულირების შემდეგ თეორია აღწერითი ენიდან ვარიაციულ ენაზე გადადის. ეს გადასვლა აუცილებელია, რადგან ფუძე-მედიუმის ფენომენოლოგიური აღწერა მეტისმეტად ფართო შეიძლება იყოს. მოქმედება კი ზღუდავს იმას, თუ რა შეიძლება ჩაითვალოს თეორიის შედეგად. RefG-ის ფორმალურ ნაწილში ნებისმიერი ფიზიკური მტკიცება უნდა მოდიოდეს ან მოქმედების ვარიაციიდან, ან ამ მოქმედებიდან მიღებული ფონური და შეშფოთებითი განტოლებებიდან.*

*მეტრიკის მიმართ ვარიაცია იძლევა ველის განტოლებას:*

```text
M_Pl^2 G_{mu nu} = T_{mu nu}^{m} + T_{mu nu}^{RefG}.
```

*ამ ფორმით RefG ინარჩუნებს აინშტაინის განტოლებათა გეომეტრიულ მხარეს. ახალი ფიზიკა თავს იჩენს წყაროს სექტორში, როგორც ფუძე-მედიუმის ეფექტური სტრეს-ენერგიის ტენზორი. ეს სტრუქტურა მნიშვნელოვანია მზის სისტემისა და გრავიტაციული ტალღების ანალიზისას, რადგან მეტრიკული ფორმალიზმი რჩება იმ საერთო ენად, რომელშიც დაკვირვებითი მონაცემები ფიქსირდება.*

*ფაზური ველის მიმართ ვარიაცია იძლევა ფაზური დენის განტოლებას. ვინაიდან ფაზური ველი `Phi` ლაგრანჟიანში მხოლოდ წარმოებულებით შედის, განტოლება ბუნებრივად იღებს შენახვის კანონის ფორმას:*

```text
nabla_mu J^mu = 0.
```

*მინიმალურ შვიდწევრიან ტრანკაციაში `J^mu` დამოკიდებულია ფაზურ ინვარიანტ `Y`-ზე და ფაზა-სივრცულ შეწყვილებაზე `Y I1`. თუ გამოიყენება მე-7 სექციაში აღწერილი შევსების ან `Z`-სექტორი, შესაბამისი ვარიაციული წვლილებიც იმავე მოქმედებიდან უნდა დაემატოს. ამ გაგებით ფაზური საათი დინამიკური სექტორია, რომლის ევოლუციაც უნდა შეესაბამებოდეს როგორც ფონურ გეომეტრიას, ისე მედიუმის ელასტიურ პასუხს.*

*სივრცული მედიუმის ველების მიმართ ვარიაცია იძლევა მყარი მედიუმის მოძრაობის განტოლებებს. ზოგადი ფორმით ისინი შეიძლება ჩაიწეროს როგორც სივრცული ველების დენის შენახვის კანონი:*

```text
nabla_mu P_A^mu = 0,
P_A^mu = dL_{RefG}/d(partial_mu phi^A).
```

*ეს განტოლებები განსაზღვრავს, როგორ ნაწილდება სივრცული ფუძის პასუხი არაერთგვაროვან ფონზე. ერთგვაროვანი ფონის შემთხვევაში პრობლემა ალგებრულ პირობებამდე მარტივდება, ხოლო სფერულ ან ტალღურ ფონზე დიფერენციალურ ამოცანას აყალიბებს.*

*ფუძე-მედიუმის ეფექტური სტრესი ლოგიკურად სამ მდგენელად იყოფა. პირველი არის ფაზური სტრესი, რომელიც `Y` და `Y^2` წევრებიდან მოდის. მეორე არის სივრცული მედიუმის სტრესი, რომელიც `I1`, `I1^2`, `I2` და `I3` ინვარიანტებით განისაზღვრება. მესამე არის შეწყვილებული სტრესი, რომელიც `Y I1` წევრიდან წარმოიშობა. სწორედ ეს უკანასკნელი აკავშირებს საათის სექტორს სივრცული მედიუმის ელასტიურ პასუხთან.*

*დიფეომორფიზმული ინვარიანტობა დამატებით იძლევა ნოეთერის თანმიმდევრულობის პირობას: სრული წყაროს კოვარიანტული დივერგენცია ქრება, როდესაც ველების განტოლებები დაკმაყოფილებულია. მინიმალურად დაკავშირებული მატერიის შემთხვევაში მატერიის სექტორის შენახვის კანონი და RefG სექტორის ვარიაციული განტოლებები ერთმანეთთან თავსებადი უნდა იყოს.*

```text
nabla_mu (T_m^{mu nu} + T_{RefG}^{mu nu}) = 0.
```

*ამავე ვარიაციული სტრუქტურიდან გამომდინარეობს სტატიის ფუნდამენტური წესიც: ნებისმიერი ფიზიკური მტკიცება შესაბამის სექტორულ გამოთვლას უნდა ეყრდნობოდეს. გალაქტიკური დინამიკის აღწერა მოითხოვს სფერულ ან დისკურ ამოხსნებს; შავი ხვრელის ფიზიკა მოითხოვს ძლიერი ველის გლობალურ ამოხსნას; ხოლო CMB-ის ანალიზი მოითხოვს ბოლცმანის იერარქიის ინტეგრაციას. მოქმედება არის საერთო საწყისი, მაგრამ ყოველი ფიზიკური სექტორი დამოუკიდებელ გამოთვლით აპარატს საჭიროებს.*

## *9. ფონური შტო და ლოკალური სტაბილურობა*

*ლოკალური სტაბილურობის პირველი შემოწმება ხორციელდება ერთგვაროვან ნორმალიზებულ ფონზე:*

```text
Y = 1,
B^{AB} = delta^{AB}.
```

*ამ ფონურ განშტოებაზე მოწმდება კინეტიკური ნიშნები. ფაზური მოდისა და სივრცული მედიუმის მოდებისათვის აუცილებელი no-ghost პირობებია:*

```text
K_PhiPhi > 0,
K_pipi > 0.
```

*მინიმალურ ტრანკაციაში ლოკალური ნიშნების დასაკონტროლებლად ჩნდება ორი კოეფიციენტური კავშირი:*

```text
c_I1sq = c_Y2,
c_I1 = c_Y - 4 c_Y2 + 2 c_YI1 - 2 c_I2 - c_I3.
```

*ამ კავშირების გათვალისწინებით, შერჩეულ ფონზე კინეტიკურად დასაშვები არე იწერება:*

```text
c_Y2 > 0,
-6 c_Y2 < c_Y + 3 c_YI1 < -2 c_Y2.
```

*ამ უტოლობის გამოყვანა პირდაპირია. ზემოთ მოცემული კოეფიციენტური კავშირების ჩასმის შემდეგ დიაგონალური კინეტიკური პრეფაქტორები იღებს ფორმას:*

```text
K_PhiPhi = c_Y + 6 c_Y2 + 3 c_YI1,
K_pipi   = -c_Y - 2 c_Y2 - 3 c_YI1.
```

*მოკლე აღნიშვნით:*

```text
Sigma = c_Y + 3 c_YI1,
```

*მივიღებთ:*

```text
K_PhiPhi = Sigma + 6 c_Y2,
K_pipi   = -Sigma - 2 c_Y2.
```

*პირობები `K_PhiPhi>0` და `K_pipi>0` შესაბამისად გვაძლევს:*

```text
Sigma > -6 c_Y2,
Sigma < -2 c_Y2.
```

*ამ ორ საზღვარს შორის ღია დასაშვები არე არსებობს მხოლოდ მაშინ, როცა `c_Y2>0`. შესაბამისად, ეს პირობა ორი დიაგონალური კინეტიკური პრეფაქტორის ერთდროული დადებითობის ზუსტი ალგებრული შედეგია.*

*ფიზიკურად ეს დასაშვები არე ნიშნავს, რომ ფაზური და სივრცული მედიუმის დიაგონალური კინეტიკური წევრები დადებითია. თუ ეს პირობა ირღვევა, ფონზე არასწორი ნიშნის კინეტიკური რეჟიმი ჩნდება. თუ პირობა სრულდება, სისტემა გადის აუცილებელ კინეტიკურ ტესტს. ეს ჯერ არ არის სრული სტაბილურობის მტკიცებულება, რადგან გრადიენტული და შერეული წევრები ცალკე უნდა შემოწმდეს.*

*გრძივი შერეული სექტორი უფრო მკაცრ ლოკალურ კრიტერიუმს აწესებს. ფაზური და გრძივი სივრცული მოდების principal-symbol იწერება კვადრატული დეტერმინანტის სახით:*

```text
det M(s) = p2 s^2 + p1 s + p0,
s = omega^2/k^2.
```

*FLRW ფონზე შესაბამისი კოეფიციენტებია:*

```text
A   = c_Y + 6 c_Y2 + 3 c_YI1/a^2,
B_L = -c_I1 - c_YI1 - (6 c_I1sq + 2 c_I2)/a^2 - c_I3/a^4,
C   = -(c_Y + 2 c_Y2)/a^2 - 3 c_YI1/a^4,
D   = (c_I1 + c_YI1)/a^2 + (10 c_I1sq + 2 c_I2)/a^4 + c_I3/a^6,
M   = 4 c_YI1/a^2.
```

*ამ აღნიშვნებით:*

```text
p2 = A B_L,
p1 = A D + B_L C - M^2,
p0 = C D.
```

*ნორმალიზებულ ერთგვაროვან ფონზე `a=1` ეს კოეფიციენტები აშკარად იწერება:*

```text
p2 =
-(c_Y + 6 c_Y2 + 3 c_YI1)
 *(c_I1 + 6 c_I1sq + 2 c_I2 + c_I3 + c_YI1),

p1 =
2*(c_I1 c_Y + 4 c_I1 c_Y2 + 3 c_I1 c_YI1
 +8 c_I1sq c_Y + 36 c_I1sq c_Y2 + 24 c_I1sq c_YI1
 +2 c_I2 c_Y + 8 c_I2 c_Y2 + 6 c_I2 c_YI1
 +c_I3 c_Y + 4 c_I3 c_Y2 + 3 c_I3 c_YI1
 +c_Y c_YI1 + 4 c_Y2 c_YI1 - 5 c_YI1^2),

p0 =
-(c_Y + 2 c_Y2 + 3 c_YI1)
 *(c_I1 + 10 c_I1sq + 2 c_I2 + c_I3 + c_YI1).
```

*ორი რეალური და დადებითი `s` ფესვის მისაღებად აუცილებელია:*

```text
p2 > 0,
p1 < 0,
p0 > 0,
p1^2 - 4 p2 p0 >= 0.
```

*ეს არის სრული ლოკალური 2x2 principal-symbol ტესტი შერჩეულ ერთგვაროვან ფონზე. იგი ამკაცრებს კინეტიკურ მოთხოვნას: გრადიენტული ნაწილი და შერეული წევრები ასევე უნდა იძლეოდეს რეალურ და დადებით გავრცელების სიჩქარეებს. დისკრიმინანტი შეგნებულად რჩება კომპაქტურ ფორმაში `Delta = p1^2 - 4 p2 p0`, რადგან ტესტი სწორედ `p0`, `p1`, `p2` კოეფიციენტებით აღდგება.*

*იმის საჩვენებლად, რომ დასაშვები არე ცარიელი არ არის, ავიღოთ 1PN განშტოებასთან თავსებადი კოეფიციენტების ერთი კონკრეტული წერტილი:*

```text
c_Y2 = 1,
c_YI1 = -6/5,
c_Y = -8/5,
c_I1 = 8/5,
c_I1sq = 1,
c_I2 = -32/5,
c_I3 = 16/5.
```

*ამ წერტილზე კინეტიკური კომბინაციაა:*

```text
c_Y + 3 c_YI1 = -26/5,
```

*რაც აკმაყოფილებს უტოლობას `-6 < -26/5 < -2`. principal-symbol კოეფიციენტები იღებს მნიშვნელობებს:*

```text
p2 = 64/25,
p1 = -304/25,
p0 = 64/25,
Delta = 76032/625.
```

*რადგან `p2>0`, `p1<0`, `p0>0` და `Delta>0`, ორივე `s` ფესვი რეალურია და დადებითი. ეს პარამეტრული მაგალითი აჩვენებს, რომ ლოკალური კინეტიკური და გრადიენტული სტაბილურობის არე არაცარიელია.*

*შევსების განშტოებაზე სტაბილურობის დამატებითი შემოწმება განსაკუთრებით მარტივია. თუ*

```text
L_S = lambda_S (S - 6)^2 - rho_0 + c_Z Z,
```

*მაშინ ერთგვაროვან ფონზე `S`-ის ფლუქტუაცია გენერირებს ფაზურ კინეტიკურ პრეფაქტორს:*

```text
K_phase = 4 lambda_S.
```

*ხოლო `Z` წევრი მყარი მედიუმის გოლდსტოუნის მოდებს ანიჭებს:*

```text
K_solid = c_Z.
```

*შესაბამისად, შევსების განშტოების აუცილებელი კინეტიკური დადებითობის პირობაა:*

```text
lambda_S > 0,
c_Z > 0.
```

*ეს პირობა მნიშვნელოვანია, რადგან საერთო ΛCDM + Solar 1PN განშტოება კინეტიკურ საზღვარზე არ უნდა იდგეს. მიუხედავად იმისა, რომ `Z` ფონზე ნულის ტოლია, ფლუქტუაციების დონეზე იგი ხსნის მყარი სექტორის კინეტიკურ არხს.*

*უფრო მკაცრ ლოკალურ შემოწმებას scalar-longitudinal principal-symbol წარმოადგენს. ფურიე-ჩანაცვლებით შევსების კვადრატული ნაწილი იწერება:*

```text
L_2 =
  4 lambda_S (omega chi - k pi_L)^2
 +c_Z (omega pi_L - k chi)^2.
```

*ამ ორი ველის principal matrix-ის დეტერმინანტი ზუსტად ფაქტორიზდება:*

```text
det M_SL =
  4 c_Z lambda_S (omega^2 - k^2)^2.
```

*თუ შემოვიღებთ `s=omega^2/k^2`, მივიღებთ:*

```text
det M_SL/k^4 =
  4 c_Z lambda_S (s - 1)^2.
```

*ამრიგად, `lambda_S>0` და `c_Z>0` პირობებში scalar-longitudinal არხი ინარჩუნებს დადებით კინეტიკურ ნიშანს, ხოლო მისი წამყვანი მახასიათებელი სინათლისებრია, `s=1`. ჩანაწერი `(s-1)^2` არ მიუთითებს ორ განსხვავებულ არალუმინალურ სიჩქარეზე; ცვლადში `s=omega^2/k^2` გაერთიანებულია ორი სინათლისებრი მიმართულება, `omega=+k` და `omega=-k`, თითოეულზე ერთგანზომილებიანი ნულოვანი სივრცით. განივი `pi_T` არხები იღებს დადებით კინეტიკურ სიმბოლოს `c_Z omega^2`; მათი გრადიენტული ნაწილი ამ სკალარულ შევსებაში ნულოვანია და solid-EFT-ის შემდგომი გრადიენტული ოპერატორებით კონტროლდება.*

*აუცილებელი კინეტიკური პირობა ლოკალურ კინეტიკურ ტესტს ხურავს. სრული სტაბილურობის პროგრამა მოიცავს გამრუდებული ფონის რეჟიმებს, არაწრფივ ევოლუციას და ყველა მოდის ერთობლივ სპექტრს. ამ სტატიაში დახურული ნაწილი არის დიაგონალური კინეტიკური არე და ლოკალური 2x2 principal-symbol კრიტერიუმი.*

*ამ არეს მნიშვნელობა ისაა, რომ მოქმედების ფორმულირების შემდეგ ჩნდება მკაფიო უტოლობები, რომლებიც ფიზიკურად დასაშვებ პარამეტრთა სივრცეს ზღუდავს. შემდეგი სექტორები ან ამ არეს უნდა შეესაბამებოდეს, ან განსხვავებულ ფონურ განშტოებაზე უნდა მუშაობდეს.*

***შედეგი 2.*** *შერჩეულ ერთგვაროვან ფონზე RefG-ის დიაგონალური კინეტიკური სექტორი აკმაყოფილებს აუცილებელ კინეტიკურ დადებითობას მაშინ და მხოლოდ მაშინ, როდესაც ზემოთ მოცემული კოეფიციენტური უტოლობები სრულდება. ლოკალური principal-symbol ტესტი ამ არეს დამატებით ზღუდავს, თუმცა მინიმუმ ერთი არაცარიელი დასაშვები წერტილი ნაჩვენებია. შევსების განშტოებაზე დამატებით მიიღება `K_phase=4 lambda_S`, `K_solid=c_Z` და `det M_SL=4 c_Z lambda_S (omega^2-k^2)^2`. შესაბამისად, `lambda_S>0` და `c_Z>0` პირობები ხურავს ამ განშტოების ლოკალურ scalar-longitudinal კინეტიკურ და principal-symbol შემოწმებას.*

## *10. FLRW ფონი და შენახვის იდენტობა*

*კოსმოლოგიურ ფონზე გამოიყენება FLRW მეტრიკა და ერთგვაროვანი ფაზური ველი `Phi(t)`. სივრცული მედიუმის ველები ამ ფონთან თავსებად ერთგვაროვან სივრცულ კონფიგურაციას იღებს. შემოვიღოთ აღნიშვნა `u(a)=dot Phi(a)`. მაშინ ინვარიანტები მარტივდება:*

```text
Y  = u^2,
I1 = 3/a^2,
I2 = 3/a^4,
I3 = 1/a^6.
```

*მეტრიკის მიმართ ვარიაციის შედეგად ეფექტური ენერგიის სიმკვრივე დროითი კომპონენტიდან იკითხება, ხოლო იზოტროპული წნევა სივრცული კომპონენტიდან. RefG სექტორის წვლილი არის:*

```text
rho_{RefG} =
  -3 c_I1/a^2
  -9 c_I1sq/a^4
  -3 c_I2/a^4
  -c_I3/a^6
  +c_Y u^2
  +3 c_Y2 u^4
  +3 c_YI1 u^2/a^2.
```

```text
p_{RefG} =
   c_I1/a^2
  -(3 c_I1sq + c_I2)/a^4
  -c_I3/a^6
  +c_Y u^2
  +c_Y2 u^4
  +c_YI1 u^2/a^2.
```

*ეს ფორმულები უშუალოდ გამომდინარეობს `L_{RefG}`-ის მეტრიკული ვარიაციიდან. კოვარიანტული დიფეომორფიზმული ინვარიანტობა იძლევა ნოეთერის იდენტობას:*

```text
nabla^mu T^{RefG}_{mu nu}
  = E_Phi partial_nu Phi + sum_A E_A partial_nu phi^A.
```

*აქ `E_Phi=0` და `E_A=0` არის ფაზური და სივრცული მედიუმის ველების მოძრაობის განტოლებები. ამ განტოლებების შესრულებისას, ანუ on-shell, ეფექტური წყარო კოვარიანტულად ინახება:*

```text
nabla^mu T^{RefG}_{mu nu} = 0.
```

*FLRW ფონზე ამ იდენტობის დროითი კომპონენტი ენერგიის შენახვის სტანდარტულ ფორმას ემთხვევა:*

```text
dot rho_{RefG} + 3 H (rho_{RefG} + p_{RefG})
  = E_Phi dot Phi.
```

*როდესაც ფაზური ველი თავის მოძრაობის განტოლებას აკმაყოფილებს, მარჯვენა მხარე ნულდება. ეს არის ბიანკის იდენტობისა და ფაზური ველის განტოლების თავსებადობის ალგებრული კონტროლი: ეფექტური სტრესი არ არღვევს ენერგია-იმპულსის შენახვის კანონს, არამედ კოვარიანტულად უკავშირდება ფაზური ველის დინამიკას. შესაბამისად, FLRW ფონური სიმკვრივე და წნევა მოქმედებიდან მიღებული შედეგია და არა დამატებითი ფენომენოლოგიური პოსტულატი.*

*მიღებული ფორმულები აჩვენებს, რომ სივრცული მედიუმის სექტორი ბუნებრივად აჩენს რამდენიმე ტიპის სკალირებას. `a^-2` წევრი სივრცული სიმრუდის მსგავსად იქცევა, `a^-4` წევრი რადიაციის მსგავსად, ხოლო `a^-6` წევრი ხისტი მატერიის მსგავსად. ეს სტრუქტურა ავტომატურად ქმნის ადრეული სამყაროს კრიტერიუმებს, რადგან ასეთი სკალირების მქონე წევრები BBN, CMB და BAO მონაცემებით მკაცრად იზღუდება.*

*კოსმოლოგიური დროის ევოლუციის მთავარი მიმართულება დინამიკური ფაზური საათია. ფაზური დენის განტოლება FLRW ფონზე იძლევა შენახულ სიდიდეს:*

```text
a^3 u (c_Y + 2 c_Y2 u^2 + 3 c_YI1/a^2) = Q_Phi.
```

*ამ ნორმალიზაციაში საერთო რიცხვითი ფაქტორი `Q_Phi` მუდმივაშია შეწოვილი. სწორედ ამ განტოლებიდან უნდა განისაზღვროს გლობალური დროის დინამიკა. შეწყვილების წევრი `c_YI1` აქტიური რჩება, ამიტომ ფაზური საათი და სივრცული მედიუმის ფონი ერთმანეთთან დაკავშირებულია. ეს შეესაბამება RefG-ის ფიზიკურ სურათს: სამყაროს ფონური დროის დინება მედიუმის მდგომარეობაზეა დამოკიდებული.*

*მარტივი კანდიდატია ნულოვანი ფაზური დენის განშტოების არანულოვანი ფესვი:*

```text
Q_Phi = 0,
u^2 = -(c_Y + 3 c_YI1/a^2)/(2 c_Y2).
```

*გვიანდელ ეპოქაში, როცა `a -> infinity`, ეს ფესვი ასიმპტოტურად გადადის:*

```text
u_inf^2 = -c_Y/(2 c_Y2).
```

*ამ ჩასმით ფაზური სექტორის გვიანი წვლილი არის:*

```text
rho_late = c_Y^2/(4 c_Y2),
p_late   = -c_Y^2/(4 c_Y2),
w = -1.
```

*მკაცრი გაყინული საათის შემთხვევისგან განსხვავებით, ამ განშტოებაზე `c_YI1` შეწყვილება არ ნულდება და ადრეულ/შუალედურ ეპოქებში `a^-2` და `a^-4` ტიპის ეფექტურ წვლილებს ცვლის. ამიტომ დინამიკური ფაზური საათი არის მთავარი კოსმოლოგიური კანდიდატი, ხოლო `dot Phi=1` მხოლოდ დამხმარე დიაგნოსტიკური რეჟიმია.*

*გვიანდელი `w=-1` მდგომარეობა არის ნულოვანი დენის განშტოების ალგებრული ლიმიტი. ამავე განშტოებაზე კინეტიკური მატრიცა, გრადიენტული მატრიცა და ადრეული სამყაროს სკალირებები ხელახლა უნდა გადამოწმდეს უკვე `u(a)`-ის ჩასმის შემდეგ. თუ რომელიმე შეზღუდვა ირღვევა, საჭიროა არანულოვანი `Q_Phi`, გარემოზე დამოკიდებული EFT კოეფიციენტები ან უფრო მაღალი რიგის სტაბილიზაციის წევრები.*

*კოსმოლოგიური დაკვირვებების რიცხვითი მორგებისთვის საჭირო ფონური ფუნქციებია:*

```text
w_{RefG}(a) =
  p_{RefG}(a,u(a)) / rho_{RefG}(a,u(a)),

Omega_{RefG}(a) =
  rho_{RefG}(a,u(a)) / (3 M_Pl^2 H_0^2).
```

*შესაბამისად, ფრიდმანის განტოლება იწერება:*

```text
E(a)^2 = H(a)^2/H_0^2
       = Omega_m/a^3
        +Omega_r/a^4
        +Omega_Lambda,bare
        +Omega_{RefG}(a).
```

*აქ `u(a)` ფაზური დენის განტოლებიდან განისაზღვრება და არ წარმოადგენს წინასწარ ხელით დაფიქსირებულ ფუნქციას. ეს იძლევა `H(z)` და `w(z)` მონაცემებთან შეპირისპირების ჩარჩოს, თუმცა სტატია ამ ეტაპზე რიცხვითი მორგების დასრულებულ შედეგს არ აცხადებს.*

*განშტოებების თავსებადობის საილუსტრაციოდ ავიღოთ ლოკალური სტაბილურობის სექციაში გამოყენებული სრული პარამეტრული წერტილის ფაზური ნაწილი:*

```text
c_Y2 = 1,
c_YI1 = -6/5,
c_Y = -8/5.
```

*ამ არჩევანზე ნულოვანი დენის განშტოება იძლევა დადებით ფესვს:*

```text
u^2(a) = 4/5 + 9/(5 a^2).
```

*გვიანდელ ეპოქაში მიიღება:*

```text
u_inf^2 = 4/5,
rho_late = 16/25,
p_late = -16/25,
w = -1.
```

*ეს რიცხვები განზომილების არმქონე ნორმალიზაციაშია. თუ ლაგრანჟიანს წინ უდგას EFT ენერგიის მასშტაბი `M_*^4`, დღევანდელ ბნელ ენერგიასთან კალიბრაცია მოითხოვს:*

```text
M_*^4 (16/25) = rho_DE.
```

*ეს მაგალითი აჩვენებს, რომ ლოკალური სტაბილურობისა და დინამიკური საათის მოთხოვნების გადაკვეთის არე არაცარიელია. რეალური `H(z)` მორგება ამ ფონური ფუნქციებით უნდა შესრულდეს ცალკე.*

*ზუსტი ფონური ΛCDM დახურვა მიიღება მაშინ, როდესაც ნულოვანი დენის დინამიკურ განშტოებაზე ზედმეტი `a^-2`, `a^-4` და `a^-6` სკალირებები კოეფიციენტური ბალანსით ქრება. ერთ-ერთი პირდაპირი ალგებრული დახურვაა:*

```text
c_I1 = c_Y c_YI1/(2 c_Y2),
c_I2 = -3 c_I1sq + 3 c_YI1^2/(4 c_Y2),
c_I3 = 0.
```

*ამ პირობებში:*

```text
rho_{RefG} = c_Y^2/(4 c_Y2),
p_{RefG} = -c_Y^2/(4 c_Y2),
E(a)^2 = Omega_m/a^3 + Omega_r/a^4 + Omega_DE.
```

*ამრიგად, ფონურ დონეზე RefG-ს აქვს ზუსტი ΛCDM განშტოება, რომელიც `c_YI1` შეწყვილების განულებას არ საჭიროებს. ეს არ არის ავტომატური შედეგი ყველა კოეფიციენტისთვის; იგი მოქმედებს ზემოთ მოცემული კოეფიციენტური ბალანსის პირობებში. მაგალითად, `c_Y=-2`, `c_Y2=1`, `c_YI1=-1/10` იძლევა დადებით საათს და განზომილების არმქონე ნორმალიზაციაში `rho_{RefG}=1`, `p_{RefG}=-1`.*

*კიდევ უფრო მჭიდრო საერთო შევსება იწერება ინვარიანტით `S = Y + 2 I1 - I3`. FLRW ფონზე პირობა `S=6` ნიშნავს:*

```text
Y(a) = dot Phi(a)^2 = 6 - 6/a^2 + 1/a^6.
```

*ეს ფუნქცია დადებითია მთელი `a>0` არეში; მისი მინიმუმია:*

```text
Y_min = 6 - 4 sqrt(2) > 0.
```

*შევსების წვლილისათვის,*

```text
L_S = lambda_S (S - 6)^2 - rho_0,
```

*ზუსტ `S=6` ზედაპირზე კვადრატული წევრი და მისი პირველი ვარიაციული წვლილი ნულდება, ხოლო მუდმივი `-rho_0` რჩება. ამიტომ ამ შევსების წვლილი იძლევა:*

```text
rho_{RefG} = rho_0,
p_{RefG} = -rho_0,
w = -1.
```

*ამგვარად, შევსების სტრუქტურა უზრუნველყოფს ზუსტ ფონურ ΛCDM ფორმას იმავე `S=6` განშტოებაზე, რომელიც შემდგომ მზის სისტემის 1PN შეზღუდვებთან თავსებადობაშიც გამოიყენება. აქ `rho_0` არ არის გამოყვანილი რიცხვი; იგი არის კოსმოლოგიური მუდმივის სიდიდის საწყისი პარამეტრი. მიღებული შედეგი არის არა Λ-სიდიდის წარმოშობა, არამედ ის, რომ Λ-სექტორი შეიძლება ჩაიწეროს ველზე-დამოკიდებული ინვარიანტით ისე, რომ იმავე განშტოებამ Solar 1PN შესაბამისობა არ დაარღვიოს.*

*შევსების სექტორში ფაზური დენი დამოუკიდებლად გამოითვლება. FLRW ფონზე:*

```text
S - 6 = u^2 + 6/a^2 - 1/a^6 - 6,
J_Phi^(S) = a^3 dL_S/du
          = 4 a^3 lambda_S u (S - 6).
```

*აქედან ჩანს, რომ ზუსტ `S=6` განშტოებაზე შევსების ფაზური დენის წვლილი ნულია. სხვა სიტყვებით, ზუსტი ΛCDM ამოხსნა თავსებადია ფაზური დენის განტოლებასთან და შინაგან წინააღმდეგობას არ წარმოქმნის. `S=6`-დან გადახრის შემთხვევაში კი შევსების სექტორი `Phi`-ს განტოლებაში დამოუკიდებელ წვლილს აბრუნებს.*

*მნიშვნელოვანია, რომ მინიმალური დინამიკური საათი და `S=6` შევსება ერთი და იგივე განშტოება არ არის. მინიმალური ნულოვანი დენის შემთხვევაში:*

```text
u_min^2 = -(c_Y + 3 c_YI1/a^2)/(2 c_Y2),
```

*ხოლო შევსების განშტოებაზე:*

```text
u_S6^2 = 6 - 6/a^2 + 1/a^6.
```

*ამ ორი ფუნქციის იდენტურად გატოლება არასინგულარული მუდმივი კოეფიციენტებით შეუძლებელია, რადგან `S=6` პროფილი შეიცავს `a^-6` წევრს, მინიმალური ნულოვანი დენის ფესვი კი არა. ამიტომ მინიმალური დინამიკური საათი რჩება ეკონომიურ კოსმოლოგიურ კანდიდატად, ხოლო `S=6/Z` ინვარიანტი არის გაფართოებული შევსება, რომელიც ზუსტ ΛCDM ფონურ ფორმას Solar 1PN-თან თავსებად განშტოებაზე ათავსებს.*

***შედეგი 3.*** *FLRW ფონზე RefG-ის ეფექტური სიმკვრივე და წნევა ალგებრულად იხურება, ხოლო ბიანკი/ნოეთერის ნაშთი ფაზური ველის მოძრაობის განტოლების პროპორციულია. დინამიკური ფაზური საათის განშტოება შენახული ფაზური დენის განტოლებით იწერება და `c_YI1` ფაზა-სივრცულ შეწყვილებას ინარჩუნებს. ნულოვანი დენის ΛCDM დახურვა მიიღება შესაბამისი კოეფიციენტური ბალანსის პირობებში, ხოლო `S=6` შევსების განშტოება იძლევა Λ-სექტორის თავსებადობის თეორემას: `rho_0` საწყისი პარამეტრის პირობებში მიიღება `rho_{RefG}=const`, `p_{RefG}=-rho_{RefG}` ისე, რომ იგივე ინვარიანტული განშტოება Solar 1PN-ს არ ეჯახება.*

## *11. კოსმოლოგიური წევრების ფიზიკური წაკითხვა*

*FLRW ფორმულებში RefG-ის ეფექტური ენერგია რამდენიმე განსხვავებულ სკალირებად იშლება. თითოეული სკალირება კოსმოლოგიურ დაკვირვებებთან პირდაპირ კავშირს ქმნის და დამოუკიდებელ ფილტრს მოითხოვს.*

*`a^-2` წევრი სივრცული სიმრუდის მსგავსად იქცევა. მისი მაღალი მნიშვნელობა ცვლის მანძილისა და წითელწანაცვლების დამოკიდებულებას და გავლენას ახდენს აკუსტიკური სკალის განსაზღვრაზე. შესაბამისად, ეს წევრი BAO-სა და CMB-ის კუთხური სკალის მონაცემებით უნდა შეიზღუდოს.*

*`a^-4` წევრი რადიაციის მსგავს ქცევას ავლენს. ადრეულ სამყაროში იგი დამატებითი რადიაციული ენერგიის სახით შეიძლება გამოჩნდეს, რაც BBN-ს, რეკომბინაციის ფიზიკასა და CMB damping tail-ს უკავშირდება. ამიტომ ამ წევრის კოეფიციენტური კომბინაცია ან დინამიკურად უნდა ჩაიხშოს, ან რიცხვითად თავსებადი იყოს არსებულ შეზღუდვებთან.*

*`a^-6` წევრი ხისტი მატერიის მსგავსად სკალირდება. წარსულისკენ ექსტრაპოლაციისას იგი რადიაციაზე სწრაფად იზრდება, რის გამოც ადრეული სამყაროს ყველაზე მკაცრ ფენომენოლოგიურ კრიტერიუმს აყალიბებს. ამ წევრის სათანადო კონტროლის გარეშე მინიმალური კოსმოლოგიური განშტოება ადრეულ ეპოქებში დაკვირვებით დაუშვებელი ხდება.*

*ფაზური წევრები `u^2` და `u^4`, სადაც `u(a)=dot Phi(a)`, საათის სექტორის ენერგიას აღწერს. დინამიკური საათის რეჟიმში `Phi(t)`-ის ევოლუცია ფაზური დენის განტოლებიდან განისაზღვრება. RefG-ის ფორმალიზმში სამყაროს ფონური დროის ცვლილება სწორედ ამ მექანიზმით შედის კოსმოლოგიურ დინამიკაში.*

*შესაბამისად, კოსმოლოგიური პროგრამა რამდენიმე საფეხურს მოიცავს: ჯერ განისაზღვრება `rho_{RefG}` და `p_{RefG}`; შემდეგ `u(a)` გამოითვლება ფაზური დენის განტოლებიდან; ამის შემდეგ იზღუდება `a^-2`, `a^-4` და `a^-6` სკალირებები; ბოლოს კი თეორია ერთობლივად უნდა შეპირისპირდეს CMB, BAO, SNe და სტრუქტურის ზრდის მონაცემებს. წინამდებარე ნაშრომის კოსმოლოგიური სექცია ამ პროგრამის ალგებრულ საფუძველს აყალიბებს და არა დასრულებულ ალბათობითი მორგების შედეგს.*

*ადრეული წევრების მინიმალური პარამეტრული ფილტრი შემდეგნაირად ფორმულირდება. განვსაზღვროთ დამატებითი კოსმოლოგიური სიმკვრივე დღევანდელი კრიტიკული სიმკვრივის ერთეულებში:*

```text
rho_extra/rho_c0 =
  Omega_2/a^2
 +Omega_4/a^4
 +Omega_6/a^6.
```

*ამ შემთხვევაში ხისტი `a^-6` წევრის ფარდობა რადიაციასთან არის:*

```text
R_6,rad(a) = Omega_6/(Omega_r a^2).
```

*BBN-ის ეპოქაში, თუ დასაშვები ფარდობითი ცდომილებაა `epsilon_BBN`, აუცილებელი პირობაა:*

```text
|Omega_6| <= epsilon_BBN * Omega_r * a_BBN^2.
```

*რეკომბინაციის ეპოქისთვის ანალოგიური პირობაა:*

```text
|Omega_6| <= epsilon_rec * Omega_r * a_rec^2.
```

*რადიაციის მსგავსი `a^-4` წევრი აისახება დამატებით ეფექტურ რადიაციულ წვლილში:*

```text
|Omega_4| <= (7/8) * (4/11)^(4/3) * Delta N_eff * Omega_gamma.
```

*სივრცული სიმრუდის მსგავსი `a^-2` წევრი კი უნდა აკმაყოფილებდეს მანძილისა და სიმრუდის კრიტერიუმს:*

```text
|Omega_2| <= epsilon_curv.
```

*პრაქტიკული რიცხვითი შემოწმებისთვის საწყისი კალიბრაციებია:*

```text
a_rec ~= 1/1090,
a_BBN ~= 10^-10 ... 10^-9,
Omega_r ~= 9 * 10^-5,
|Omega_k| <~ 10^-3,
Delta N_eff = O(0.1).
```

*ეს ეტაპი თითოეულ სკალირებას საკუთარ დაკვირვებით ფილტრს უდგენს. `a^-6` წევრი განსაკუთრებით მკაცრ კონტროლს ექვემდებარება, რადგან მისი ფარდობა რადიაციასთან წარსულში `1/a^2` კანონით იზრდება. Planck-ის, BBN-ისა და BAO/SNe მონაცემებთან სრული ალბათობითი მორგება შემდეგი ფენომენოლოგიური ნაბიჯია.*

## *12. მკაცრი საათის დიაგნოსტიკა და დინამიკური საათი*

*სექტორების ცალკე დახურვის შემდეგ საჭიროა შემოწმდეს, შესაძლებელია თუ არა ერთი და იმავე გლობალურმა განშტოებამ ერთდროულად დაიჭიროს კოსმოლოგიური ფონი და Solar 1PN ზღვარი. ამისათვის სასარგებლო საკონტროლო ტესტია გაყინული, ანუ მკაცრი საათის დიაგნოსტიკა. ამ ტესტში ფაზურ საათს ხელით ვყინავთ:*

```text
dot Phi = 1.
```

*ეს პირობა არ არის RefG-ის ფიზიკური პოსტულატი და არც საბოლოო კოსმოლოგიური განშტოება. იგი არის დიაგნოსტიკური ჩასმა: ვამოწმებთ, რა იძულებით კოეფიციენტურ პირობებს მოგვცემს თეორია, თუ ფაზურ საათს დინამიკას მოვაშორებთ.*

*ამ არჩევანში Λ-ტიპის ფონური დახურვა მოითხოვს:*

```text
c_Y = -2 c_Y2,
c_YI1 = 0.
```

*ეს უკვე პრობლემური სიგნალია, რადგან `c_YI1=0` თიშავს ფაზურ საათსა და სივრცულ ელასტიურ ფონს შორის შეწყვილებას. სწორედ ეს შეწყვილება არის მინიმალური RefG კონსტრუქციის მნიშვნელოვანი ნაწილი.*

*მეორე მხრივ, სუსტი ველის არატრივიალური Solar 1PN განშტოება მოითხოვს:*

```text
c_Y = -4 c_Y2 - 2 c_YI1.
```

*თუ გაყინული საათის Λ-დახურვას და Solar 1PN პირობას ერთად მოვითხოვთ, მივიღებთ:*

```text
-2 c_Y2 = -4 c_Y2 - 2 c_YI1,
c_YI1 = 0.
```

*აქედან გამოდის:*

```text
c_Y2 = 0,
c_YI1 = 0,
c_Y = 0.
```

*ანუ გაყინული საათის გლობალურად გამოყენება ფაზურ არაწრფივობასა და ფაზა-სივრცულ შეწყვილებას დეგენერირებულ ზღვარზე აგდებს. ამიტომ `dot Phi=1` არ უნდა წავიკითხოთ როგორც თეორიის არჩეული საათი; იგი მხოლოდ აჩვენებს, რატომ არ არის მკაცრი საათის მოკლე გზა საკმარისი საერთო კოსმოლოგია + Solar 1PN დახურვისთვის.*

*ამ დასკვნის შემდეგ კოსმოლოგიური კანდიდატია დინამიკური ფაზური საათი. აქ საათი ხელით აღარ ფიქსირდება; ის ფაზური დენის განტოლებიდან განისაზღვრება. თუ `u(a)=dot Phi(a)`, მაშინ FLRW ფონზე:*

```text
a^3 u (c_Y + 2 c_Y2 u^2 + 3 c_YI1/a^2) = Q_Phi.
```

*ამ განშტოებაში `c_YI1` აქტიური რჩება. ამიტომ კოსმოლოგიური დროის ევოლუცია და სივრცული მედიუმის ფონური პასუხი ერთი და იმავე ფაზა-სივრცული შეწყვილებით იკითხება. ეს არის დინამიკური საათის უპირატესობა გაყინულ დიაგნოსტიკასთან შედარებით.*

*ამავე იდეას უფრო მკაცრი, გაფართოებული ფორმით აყალიბებს შევსების განშტოება:*

```text
S = Y + 2 I1 - I3 = 6.
```

*ეს პირობა არ არის კიდევ ერთი ხელით არჩეული საათი. იგი არის ინვარიანტული შეზღუდვა, რომელიც `Y`, `I1` და `I3` კომბინაციას აფიქსირებს. FLRW ფონზე იგი განსაზღვრავს `Y(a)=dot Phi(a)^2` პროფილს, ხოლო Solar 1PN სექტორში იმავე ალგებრული კომბინაცია არ წარმოქმნის `O(U)` ლოკალურ ნაშთს. გაყინული საათისგან განსხვავებით, `S=6` არ მოითხოვს `c_YI1` შეწყვილების განულებას.*

*შევსების განშტოება უნდა გაიმიჯნოს მინიმალური დინამიკური საათისგან. მინიმალური დინამიკური საათი არის ეკონომიური კოსმოლოგიური კანდიდატი, რომელიც ფაზური დენის განტოლებით მუშაობს. `S=6/Z` კი არის გაფართოებული EFT შევსება, რომელიც ზუსტ ΛCDM ფონურ ფორმას Solar 1PN-თან თავსებად ერთ განშტოებაზე აკავშირებს. ეს ორი გზა ერთმანეთის შემცვლელი არ არის; ისინი სხვადასხვა დონის კონსტრუქციებია.*

*უფრო ფართო EFT-ში კოეფიციენტები შეიძლება ლოკალურ გარემოზე დამოკიდებულ ეფექტურ სიდიდეებად განზოგადდეს:*

```text
c_i -> c_i(chi),
```

*სადაც `chi` შეიძლება იყოს სიმკვრივის, სიმრუდის, ფაზური ფონის ან სივრცული მედიუმის მდგომარეობის სკალარი. ეს არის შესაძლო გაფართოება და არა ამ სტატიის მინიმალური ბირთვის მიღებული შედეგი. მთავარი დასკვნა უფრო ვიწროა: გაყინული საათი დიაგნოსტიკაა, ხოლო ფიზიკური კოსმოლოგიური განშტოება დინამიკურ ფაზურ საათს ან `S=6/Z` შევსების განშტოებას უნდა ეყრდნობოდეს.*

## *13. სუსტი ველი და მზის სისტემა*

*სუსტი ველის ზღვარში მეტრიკა პოსტნიუტონურ რიგებად იშლება. ამ სექციაში სამი დაკავშირებული, მაგრამ განსხვავებული ანზაცი გამოიყენება. მათი ერთმანეთში არევა განსაკუთრებით სახიფათოა, რადგან 1PN დახურვა, იზოტროპული 2PN დახურვა და `S=6` შევსება სხვადასხვა განშტოებას აღწერს.*

| *ანზაცი*                         | *კოორდინატი* | *მეტრიკის ფორმა*                | *მყარი სექტორის საკუთარი მნიშვნელობები* | *გამოყენება*                                                                                                                       |
| :--------------------------------------- | :----------------------- | :--------------------------------------------- | :-------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------- |
| *ფართობის რადიუსის PN* | `r_area`               | `ds^2 = B_t dt^2 - A_r dr^2 - r^2 dOmega^2`  | `(1/A_r, 1, 1)`                                                           | *მინიმალური შვიდკოეფიციენტიანი ტრანკაციის 1PN სტრესული დახურვა*                         |
| *იზოტროპული 2PN*             | `r_iso`                | `ds^2 = A_t dt^2 - B_r(dr^2 + r^2 dOmega^2)` | `(1/B_r, 1/B_r, 1/B_r)`                                                   | *მინიმალური იზოტროპული უსტრესო დახურვა და `b_2/q_2PN` კოეფიციენტების გამოყვანა* |
| *`S=6` შევსების 1PN*         | `r_area`               | `A_r = 1 + 2U + 4U^2`, `B_t = 1 - 2U`      | `(1/A_r, 1, 1)`                                                           | *ზუსტი ΛCDM ფონისა და Solar 1PN თავსებადობის საერთო შევსების განშტოება*                             |

*სტატიკური, სფერული, ფართობის რადიუსის ერთეულოვან ყალიბში სივრცული მყარი სექტორის საკუთარი მნიშვნელობებია `B^{AB}=(1/A_r,1,1)`. შესაბამისად:*

```text
Y  = 1/B_t,
I1 = 2 + 1/A_r,
I2 = 1 + 2/A_r,
I3 = 1/A_r.
```

*იზოტროპულ კოორდინატებში საკუთარი მნიშვნელობები სამივე მიმართულებით იდენტურია:*

```text
Y  = 1/A_t,
I1 = 3/B_r,
I2 = 3/B_r^2,
I3 = 1/B_r^3.
```

*ეს პირობა კი არატრივიალურ 1PN განშტოებას აქრობს. ამიტომ 2PN ნაშთი მზის სისტემის ფალსიფიკაციის ადგილი და პროგნოზული შესაძლებლობაა. თუ RefG-ს მზის სისტემაში GR-ისგან განსხვავება აქვს, ის ამ ნაშთის კონტროლში უნდა გამოჩნდეს. თუ დაკვირვებები ამ ნაშთს მკაცრად ზღუდავს, ეს პირდაპირ შეზღუდავს `c_Y2` და `c_YI1` კომბინაციებს.*

*აქ მტკიცება მაქსიმალურად კონკრეტულია: 1PN რიგში არსებობს არატრივიალური განშტოება, ხოლო 2PN ზუსტად უსტრესო დახურვა იმავე მინიმალურ განშტოებაზე აღარ ტოვებს თავისუფალ არანულოვან `c_Y2`, `c_YI1` წყვილს. ამიტომ მზის სისტემის ეს ნაწილი არის ალგებრული განშტოების თეორემა მკაფიო ნაშთით.*

*2PN ნაშთის დაკვირვებით ენაზე გადასაყვანად საჭიროა გარე მეტრიკიდან ოპტიკური ინდექსის გამოყვანა. ისტორიულად განიხილებოდა პირობითი ოპტიკური კანდიდატი: თუ სუსტი ველის გარე ოპტიკური განშტოება დაიხურებოდა ფორმით*

```text

```

*ხოლო GR-ის იზოტროპული Schwarzschild ინდექსია*

```text
n_GR = (1 + r_g/(2r))^3/(1 - r_g/(2r)),
```

*მაშინ 1PN ნაწილი იდენტურია, ხოლო 2PN განსხვავება იწყება `Delta q_2PN = 1/4` კოეფიციენტით. ამ პირობის მეტრიკული შინაარსი იზოტროპულ 2PN ხიდში ჩანს. თუ*

```text
A(r) = 1 - 2u + 2 beta u^2,
B(r) = 1 + 2 gamma u + b_2 u^2,

```

*მაშინ სინათლის ოპტიკური ინდექსია:*

```text
n = sqrt(B/A)
  = 1 + (1 + gamma)u
    + (b_2/2 - beta - gamma^2/2 + gamma + 3/2)u^2
    + O(u^3).
```

*GR-ის იზოტროპულ Schwarzschild მეტრიკაში `gamma=beta=1` და `b_2=3/2`, ამიტომ:*


*ხოლო `n_{RefG}=exp(2u)=1+2u+2u^2+O(u^3)` იმავე `gamma=beta=1` პირობებში მოითხოვს:*

*ამრიგად, ძველი 2PN ოპტიკური კანდიდატი მეტრიკის კონკრეტულ 2PN სივრცულ კოეფიციენტად ითარგმნება. შესამოწმებელი კითხვა არის: იძლევა თუ არა RefG-ის გარე სფერული ამოხსნა `b_2=2`-ს?*

*ეს კითხვა პირდაპირ შემოწმდა მინიმალურ იზოტროპულ ერთეულოვანი ყალიბის დახურვაში. ავიღოთ:*

*მოთხოვნაა, რომ RefG-ის ფონური სტრესი `T^t_t` და იზოტროპული სივრცული სტრესი `T^i_i` გაქრეს `O(u^2)` რიგის ჩათვლით. ალგებრული ამოხსნა იძლევა ორ გზას. პირველი არის ტრივიალური სექტორი:*

```text
c_Y = c_Y2 = c_YI1 = c_I1 = c_I3 = 0,

```

*მეორე არის არატრივიალური, ზუსტად უსტრესო 2PN განშტოება:*


## *15. CMB-ის იგივე-შეყვანის თანმიმდევრულობის შემოწმება*

*CMB სექტორში განისაზღვრება ერთნაირი შეყვანის ჩაკეტილი FLRW განშტოება:*

```text
Phi_0 = 0,
X_0 = 0.
```

*ეს განშტოება კოსმოსური დროის ჩაკეტვით იწყება. ერთგვაროვან ფონზე `g_tt=1` და ბიკონფორმული დროის ფაქტორი `exp(Phi_0)` ერთად იძლევა:*

```text
exp(Phi_0) = 1,
Phi_0 = 0,
dot Phi_0 = 0,
X_0 = 0.
```

*ამ პირობებში ფაზური ფონური სტრესი იმავე-მატერიის მეტრიკულ განშტოებაში ნულდება. მატერიის შემადგენლობა, რეკომბინაციის ფიზიკა და საწყისი პერტურბაციების სპექტრი იგივე შეყვანებად რჩება. RefG-ის ჩაკეტილი მინიმალური მეტრიკული სექტორი ახალ წრფივ CMB წყაროს არ ამატებს.*

*ამ პირობებში ბელინი-სავიცკის პარამეტრები ქრება:*

```text
alpha_K = 0,
alpha_B = 0,
alpha_M = 0,
alpha_T = 0.
```

*წრფივი რიგის მეტრიკული წყარო ასევე არ გენერირდება, რადგან ფაზური სტრესი კვადრატული რიგიდან იწყება:*

```text
T_scalar^(1) = 0.
```

*ამიტომ პუასონის განტოლება, მეტრიკული slip განტოლება, ფოტონ-ბარიონული სითხის იერარქია, ნეიტრინოების წრფივი წვლილი და Weyl პოტენციალის წყარო უცვლელი რჩება იგივე შეყვანების პირობებში. აკუსტიკური ჰორიზონტისა და კუთხური სკალის ცვლილებაც ნულის ტოლია:*

```text
delta r_s = 0,
delta theta_* = 0,
delta Weyl = 0.
```

*თუ გაფართოების ისტორია, მატერიის შემცველობა, რეკომბინაციის ფიზიკა და საწყისი სპექტრი იგივეა, მაშინ წრფივი აინშტაინ-ბოლცმანის იერარქია უცვლელი რჩება [11-14]. შესაბამისად:*

```text
C_ell^{RefG} = C_ell^LCDM
```

*იგივე შეყვანების პირობებში. იგივე ეხება პირველადი აკუსტიკური პიკების მდებარეობას, წრფივ ლინზირებას და ISW წყაროს, თუ Weyl პოტენციალი იგივე რჩება.*

*იგივე-შეყვანის შემოწმება უნდა გაიაროს `S=6` შევსების განშტოებამაც. ამ განშტოებაზე ჩაკეტილი წრფივი CMB სექტორი განისაზღვრება პირობებით:*

```text
delta S = 0,
delta Z_linear = 0.
```

*ამ შემთხვევაში შევსების სექტორის ფონური ნაწილი კოსმოლოგიური მუდმივასავით იქცევა:*

```text
rho_{RefG} = rho_0,
p_{RefG} = -rho_0,
rho_{RefG} + p_{RefG} = 0.
```

*შესაბამისად, წრფივ აინშტაინ-ბოლცმანის წყაროებში დამატებითი RefG წვლილი ნულდება:*

```text
delta rho_{RefG} = 0,
delta p_{RefG} = 0,
momentum_{RefG} = 0,
shear_{RefG} = 0.
```

*აქედან გამომდინარეობს:*

```text
Poisson_extra_source = 0,
slip_extra_source = 0,
photon_baryon_extra_force = 0,
lensing_extra_source = 0,
ISW_extra_source = 0.
```

*ეს შედეგი თავსებადია შევსების პერტურბაციის ლოკალურ principal-symbol შემოწმებასთან, სადაც აქტიურ scalar-longitudinal მოდას აქვს:*

```text
det M_SL/k^4 = 4 c_Z lambda_S (s - 1)^2.
```

*მაგრამ იგივე-შეყვანის CMB განშტოებაში ეს მოდა `delta S=0` პირობით ჩაკეტილია და ფოტონ-ბარიონულ ბოლცმანის იერარქიაში დამატებითი წყაროს სახით არ შედის.*

*ეს არის იგივე-შეყვანის CMB განშტოების თანმიმდევრულობის იდენტობა. თუ მოდიფიკაციის სექტორი ჩაკეტილია და ყველა საწყისი შეყვანა ემთხვევა, მაშინ `C_ell` სპექტრის დამთხვევა მათემატიკურად მოსალოდნელია. მისი ფიზიკური მნიშვნელობა არის უსაფრთხო მეტრიკული ლიმიტის არსებობა, სადაც RefG ადრეული სამყაროს წრფივ პერტურბაციებს იმავე შეყვანების პირობებში იდენტურად იმეორებს.*

*ნაწილაკოვანი ბნელი მატერიის გარეშე CMB-ის აღწერა ცალკე აქტიური წყაროს ამოცანაა. იგი მოითხოვს ახალ დინამიკურ ცვლადს ან ეფექტური მედიუმის პერტურბაციას, ბოლცმანის იერარქიაში მის ინტეგრირებას და შემდგომ Planck/BAO/ლინზირების მონაცემებთან ალბათობით შეპირისპირებას. იგივე ითქმის აქტიურ შევსების განშტოებაზეც, სადაც `delta S` აღარ არის ჩაკეტილი და `S/Z` მოდა დამოუკიდებლად ვრცელდება. წინამდებარე სტატიის CMB მონაკვეთი ადასტურებს მხოლოდ იმას, რომ იგივე-შეყვანის ჩაკეტილ განშტოებაზე RefG სტანდარტულ წრფივ მეტრიკულ შედეგს იდენტურად აღადგენს.*

*აქტიური `S/Z` შევსების სექტორში წყაროს რიგითობაც დამოუკიდებლად არის შემოწმებული. ზუსტ ფონზე:*

```text
S - 6 = eps s_1,
Z = eps^2 z_2,
L_S = lambda_S eps^2 s_1^2 + c_Z eps^2 z_2 - rho_0.
```

*ამიტომ წრფივი წყაროს კოეფიციენტი ნულის ტოლია:*

```text
dL_S/deps |_(eps=0) = 0.
```

*ეს მნიშვნელოვანი უსაფრთხოების შედეგია: ნულოვანი ფონური წყაროს მქონე `S=6` შევსება სტანდარტულ წრფივ CMB წყაროებს არ ცვლის. მეორე მხრივ, ნაწილაკოვანი ბნელი მატერიის გარეშე CMB განშტოება მოითხოვს არანულოვან აქტიურ ფონს, მატერია/მედიუმის პირდაპირ შეწყვილებას ან RefG-ის ეფექტურ სითხეს საკუთარი სიმკვრივის კონტრასტით, ეილერის განტოლებითა და წანაცვლებითი სტრესის დახურვით.*

*დროითი სკალა `13.8 Gyr` ამ ჩარჩოში არის დღევანდელი კოსმოლოგიური ასაკის დაკვირვებითი კალიბრაცია, რომელიც სტანდარტული კოსმოლოგიური მონაცემებიდან მოდის [14]. RefG-ის დროითი სექტორის განსხვავებული კოსმოლოგიური კალიბრაცია ცალკე კოსმოლოგიურ მორგებაში უნდა შეფასდეს.*

***შედეგი 6.*** *ერთნაირი შეყვანის ჩაკეტილ FLRW განშტოებაში RefG წრფივ აინშტაინ-ბოლცმანის იერარქიას იმავე შეყვანების პირობებში იდენტურად იმეორებს. `S=6` შევსების განშტოებაზეც, როცა `delta S=0` და `delta Z_linear=0`, დამატებითი პუასონის, slip, ლინზირებისა და ISW წყაროები ნულის ტოლია. ნულოვანი ფონიდან აქტიური `S/Z` პერტურბაციის წრფივი წყაროც ნულია, რადგან შევსების სტრესი `eps^2` რიგიდან იწყება. ამიტომ პირველადი CMB სპექტრი სტანდარტულ შედეგს ემთხვევა მხოლოდ ერთნაირი შეყვანის პირობებში. რეალური CMB კრიტერიუმი ძალაში შედის მაშინ, როცა `Phi_0 != 0`, `delta S` აქტიურია არანულოვანი ფონური წყაროდან, მედიუმის პერტურბაციები აქტიურია ან ნაწილაკოვანი ბნელი მატერია RefG-ის ეფექტური სექტორით იცვლება.*

## *16. ძლიერი ველი და ეკრანირების მინიმალური კარიბჭე*

*ამ სტატიაში ძლიერი ველის რეჟიმი არ განიხილება როგორც კომპაქტური ობიექტების შესახებ დასრულებული მტკიცება. საბაზისო სტატიკური ექსპონენციური გარე მოდელი აჩვენებს, რომ სასრული რადიუსის მქონე Killing horizon არ წარმოიქმნება:*

```text
exp(-r_s/r) > 0,  r > 0.
```

*ეს არის გეომეტრიული საბაზისო მოდელი. სუსტი ველის ტესტების გავლის შემდეგაც, თეორია ძლიერი ველის რეჟიმში დამოუკიდებელ შემოწმებას მოითხოვს, როგორც ეს სკალარ-ტენზორული ძლიერი ველის ტესტების ლიტერატურაშიც ჩანს [30,31]. ძლიერი ველის ფიზიკური დასკვნისთვის საჭიროა წყაროს დახურვა იმავე RefG მოქმედებიდან, სასრულ-ბირთვიანი შეწყვილების სტრესი, შეწყვილებული პერტურბაციების სტაბილურობა, QNM/echo გადაცემის ფუნქციები, მბრუნავი გარე ამოხსნა და EHT/ნეიტრონული ვარსკვლავების მონაცემებთან ალბათობითი შედარება.*

*ამ მიზეზით ძლიერი ველის სექტორი ამ ნაშრომში კვლევის საზღვრად არის გამოყოფილი და არა დასრულებულ დასკვნად.*

*ეკრანირება არ გამოიყენება მინიმალური იზოტროპული განშტოების დაცვის მექანიზმად. ეს განშტოება ცალკე დიაგნოსტიკაა, ხოლო კალიბრირებული `S=6` განშტოება მზის სისტემაში GR-თან თავსებადია მასშტაბური ჩახშობის გამო. ამიტომ მზის სისტემის დაკვირვებებთან თავსებადობისთვის დამატებითი screening არ არის საჭირო პირობა.*

*თუ სხვა განშტოება, მათ შორის `q_2PN=10` ან ძლიერი ველის ექსპონენციური რეჟიმი, ფიზიკურ სექტორად აირჩევა, მაშინ ეკრანირება თავიდან უნდა გამოიყვანოს იმავე მოქმედებიდან. ასეთი მექანიზმი ვერ ჩაიწერება მხოლოდ ფენომენოლოგიურ ამპლიტუდად; მას უნდა ჰქონდეს წყაროს დახურვა, სტაბილურობა და დაკვირვებითი შეპირისპირება.*

***შედეგი 7.*** *ძლიერი ველის სექტორი ამ სტატიაში მკაცრი ფარგლის მიღმა რჩება. სტატიკური უჰორიზონტო შედარებითი ამოხსნა არსებობს, მაგრამ კომპაქტური ობიექტების სიცოცხლისუნარიანობა, მბრუნავი ძლიერი ველის ფენომენოლოგია, QNM/echo სიგნალები, EHT/ნეიტრონული ვარსკვლავების შედარება და ეკრანირების მექანიზმი დასრულებულ შედეგებად არ განიხილება შესაბამისი სრული გამოთვლების გარეშე.*

## *17. ფალსიფიკაციის პრინციპი*

*RefG-ის მინიმალური ბირთვი ფალსიფიცირებადი უნდა იყოს. აქ ფალსიფიკაცია ნიშნავს კონკრეტულ კრიტერიუმებს, რომელთა დარღვევაც შესაბამის განშტოებას გამორიცხავს ან გაფართოებულ EFT-ს საჭიროებს. ამ სტატიის შედეგები ოთხ კატეგორიად უნდა წავიკითხოთ: დახურული ალგებრული შედეგი, პირობითი განშტოება, დაკვირვებით შესამოწმებელი კრიტერიუმი და გაფართოებული EFT-ის საჭიროება.*

*ლოკალური სტაბილურობის კრიტერიუმი არის კინეტიკურად დასაშვები არე და principal-symbol ტესტი. თუ სხვა ფიზიკური მოთხოვნები ამ პარამეტრულ არეს ცარიელს გახდის, შესაბამისი განშტოება არაჯანსაღია. ეს არის პირველი, ლოკალური ფალსიფიკაციის კარი.*

*კოსმოლოგიური კრიტერიუმი მოიცავს ადრეული სამყაროს სკალირებებს და `H(z)`/`w(z)` მორგებას. მინიმალური დინამიკური საათის შემთხვევაში `a^-2`, `a^-4` და `a^-6` წევრები ან დინამიკურად უნდა ჩაიხშოს, ან კოეფიციენტური ბალანსით უნდა გაქრეს. `S=6` შევსების განშტოებაზე ფონური ΛCDM ნაწილი ალგებრულად იკეტება, მაგრამ შემდგომი კოსმოლოგიური კრიტერიუმი პერტურბაციების სტაბილურობასა და ალბათობით მორგებაზე გადადის.*

*მზის სისტემის კრიტერიუმი ორ ნაწილად იყოფა. პირველი არის უპირატესი ჩარჩოს PPN პარამეტრები `alpha_1`, `alpha_2`, `alpha_3`; მინიმალური მოძრავი წყაროს ჯაჭვი მათ ნულად აყენებს. მეორე არის კალიბრირებული `S=6` განშტოების 2PN გარე ქცევა. ბნელი-ენერგიის მასშტაბზე ეს განშტოება GR-თან თავსებადია `O(10^-35)` ჩახშობით; იგივე დასკვნა სრული თვით-თანმიმდევრული გარე ODE ამოხსნით მკაცრდება. მინიმალური იზოტროპული განშტოება ცალკე დიაგნოსტიკად რჩება და არ არის ძირითადი თეორიის მზის პროგნოზი.*

*გრავიტაციული ტალღების კრიტერიუმში ტენზორული სიჩქარის არხი იძლევა `alpha_T=0` შედეგს. შემდგომი ტალღური ფენომენოლოგია მოიცავს მასიურ დისპერსიას, დამატებით პოლარიზაციებს, ორმაგი პულსარების ენერგიის დანაკარგს და ტალღის სრული ფორმის შედარებას. თუ დამატებითი მოდები დაკვირვებით აკრძალულ ამპლიტუდას იძლევა, შესაბამისი ტალღური განშტოება ფალსიფიცირდება.*

*ძლიერი ველის კრიტერიუმი ამ სტატიაში კვლევის საზღვარია. სტატიკური უჰორიზონტო შედარებითი ამოხსნა არის მხოლოდ გეომეტრიული საწყისი. ძლიერი ველის დასკვნისთვის საჭიროა წყაროს დახურვა იმავე RefG მოქმედებიდან, სასრულ-ბირთვიანი შეწყვილების სტრესი, მბრუნავი გარე ამოხსნა, შეწყვილებული პერტურბაციები, QNM/echo სიგნალები და EHT/ნეიტრონული ვარსკვლავების მონაცემებთან ალბათობითი შედარება.*

*CMB-ის კრიტერიუმიც ორ ნაწილად იყოფა. ერთნაირი შეყვანის განშტოება არის თანმიმდევრულობის იდენტობა: ჩაკეტილ უსაფრთხო ლიმიტში RefG სტანდარტულ წრფივ მეტრიკულ შედეგს იმავე შეყვანების პირობებში იმეორებს. `S=6` შევსება ამ ტესტს გადის `delta S=0` და `delta Z_linear=0` პირობებში. ნულოვანი ფონიდან აქტიური `S/Z` წყარო წრფივ რიგში ნულია. ნაწილაკოვანი ბნელი მატერიის გარეშე CMB კი ცალკე აქტიური წყაროს ამოცანაა და მოითხოვს სრულ აინშტაინ-ბოლცმანის და ალბათობით ანალიზს.*

*გლობალური კრიტერიუმი არის განშტოებების თავსებადობა. გაყინული საათის მოკლე გზა ამ კრიტერიუმს ვერ აკმაყოფილებს, რადგან `c_YI1` შეწყვილებას თიშავს. დინამიკური ფაზური საათი ამ შეწყვილებას ინარჩუნებს, ხოლო გაფართოებული `S = Y + 2 I1 - I3 = 6` შევსება საერთო ფონურ ΛCDM და Solar 1PN დახურვას ერთ განშტოებაში ათავსებს. ამ განშტოების მზის 2PN ქცევა GR-თან თავსებადია ბნელი-ენერგიის მასშტაბური ჩახშობის გამო; შემდგომი ანალიზი გადადის გამრუდებულ-ფონურ სტაბილურობაზე, ნაწილაკოვანი ბნელი მატერიის გარეშე აქტიურ CMB განშტოებაზე და ძლიერი ველის სექტორზე.*

## *დასკვნა*

*წინამდებარე ნაშრომში რეფრაქციული გრავიტაცია ჩამოყალიბებულია როგორც მეტრიკულ გრავიტაციაზე დაშენებული ფაზური ეფექტური ველის თეორია სივრცული მედიუმის სექტორით. მოქმედების ბირთვს აინშტაინ-ჰილბერტის წევრი წარმოადგენს, ხოლო დამატებითი სექტორი აერთიანებს `G2(X)`-თან თავსებად ფაზურ სკალარს, solid-EFT ტიპის სივრცულ მედიუმს და ფაზა-სივრცულ ჯვარედინ წევრებს. ამ ფორმით RefG იძლევა სუსტი ველის რეფრაქციულ ჯაჭვს და მასთან თავსებად შევსების განშტოებას; ძლიერი ველი, სრული არასფერული გალაქტიკური PDE და აქტიური CMB განშტოება ცალკე გამოთვლით სექტორებად რჩება.*

*ძირითად შედეგებში შედის მოქმედების შიდა ალგებრა, `Y=-2X` ნოტაციური თარგმანი, FLRW ფონზე სიმკვრივისა და წნევის (`rho/p`) ფორმულები, ბიანკი-ნოეთერის იდენტობა, დინამიკური ფაზური დენის განტოლება, ერთგვაროვანი ფონის კინეტიკურად დასაშვები არე, სტატიკური სფერული 1PN განშტოება, სუსტი ველის რეფრაქციული ძალის ჯაჭვი და no-go ლემა, რომლის მიხედვითაც მუდმივ-კოეფიციენტიანი მინიმალური ბირთვი ერთდროულად ვერ ხურავს ზუსტ ΛCDM ფონსა და Solar 1PN-ს სტაბილურ არატრივიალურ სექტორში. რეფრაქციულ ჯაჭვში `p01` მოქმედების სტრესი იძლევა `h_eff` წყაროს, `n_eff=exp(h_eff)` იძლევა ტესტ-მატერიის უნივერსალურ რეფრაქციულ ძალას, `p10` პირველი რიგით არჩევს ბიკონფორმულ განშტოებას, Bernoulli-რადიალური პასუხი აბრუნებს ნიუტონს, წყარო ცენტრში რეგულარულია და გარე კოეფიციენტი ასიმპტოტური მუხტით ფიქსირდება, ხოლო კოჰერენტული ვორტექსული განშტოება იძლევა `a0=cH/(2*pi)`, `mu(x)=x/(1+x)` და BTFR-ს. ამავე სტრუქტურაში გამოიყოფა საერთო შევსების ინვარიანტი*

```text
S = Y + 2 I1 - I3 = 6.
```

*ეს განშტოება იძლევა ზუსტ `ΛCDM` ფონურ ფორმას `rho_0` საწყისი პარამეტრით და Solar 1PN შესაბამისობას არ არღვევს, თუ ერთგვაროვანი `Λ`-ტიპის სტრესი ადგილობრივ წყაროდ არ ჩაითვლება. ამით იგი თავსებადობის თეორემაა და არა Λ-სიდიდის გამოყვანა. მისი ლოკალური scalar-longitudinal შემოწმება იძლევა დადებით კინეტიკურ პრეფაქტორებს*

```text
K_phase = 4 lambda_S,
K_solid = c_Z,
lambda_S > 0,
c_Z > 0,
```

*და principal-symbol დეტერმინანტს*

```text
det M_SL = 4 c_Z lambda_S (omega^2 - k^2)^2.
```

*ამიტომ ამ ლოკალურ განშტოებაზე წამყვანი scalar-longitudinal მახასიათებელი სინათლისებრია, `omega^2=k^2`. სრული გლობალური ან გამრუდებულ-ფონური სტაბილურობა ცალკე ანალიზს მოითხოვს.*

*მზის სისტემის 1PN დონეზე სტატიკური სფერული ჯაჭვი იძლევა `gamma=1` და `beta=1`, ხოლო მინიმალური მოძრავი წყაროს ჯაჭვი უპირატესი ჩარჩოს პარამეტრებისთვის იძლევა `alpha_1=alpha_2=alpha_3=0`. ტენზორული ტალღის სიჩქარის არხში მინიმალური ჰორნდესკის/`Y` ხიდი იძლევა `G4=const`, `G5=0` და `alpha_T=0`, ანუ ტენზორული სიჩქარე სინათლის სიჩქარეს ემთხვევა. სრული ტალღური ფენომენოლოგია, მათ შორის დამატებითი პოლარიზაციები, დისპერსია, ამპლიტუდის ევოლუცია და ტალღის სრული ფორმის შედარება, ცალკე კვლევას საჭიროებს.*

*ჩაკეტილ ერთნაირი შეყვანის CMB განშტოებაზე, `delta S=0` და `delta Z_linear=0` პირობებში, დამატებითი პუასონის, სრიალის, ლინზირებისა და ISW წყაროები ნულის ტოლია. ამავე პირობებში ნულოვანი ფონიდან აქტიური `S/Z` წყარო წრფივ რიგში არ გენერირდება. ეს არის CMB-ის თანმიმდევრულობის იდენტობა იმავე მატერიის შეყვანით; იგი არ ნიშნავს, რომ RefG უკვე ცვლის ნაწილაკოვან CDM-ს. ნაწილაკოვანი CDM-ის გარეშე CMB განშტოება საჭიროებს აქტიური `S/Z` ველების ბოლცმანის სისტემასა და ალბათობით მორგებას.*

*მზის სისტემის 2PN სექტორში მინიმალური იზოტროპული უსტრესო დახურვა ცალკე ალგებრულ განშტოებას იძლევა და ძველი ექსპონენციური ოპტიკური კანდიდატი, `b_2=2`, ამ გზით არ რეალიზდება. ეს განშტოება არ არის კალიბრირებული `S=6` შევსების მზის პროგნოზი. ბნელი-ენერგიის მასშტაბით კალიბრირებული `S=6` განშტოება მზის გარე ველში GR-თან თავსებადია `q_2PN=7/4+O(10^-35)` მასშტაბური შედეგით; სრული თვით-თანმიმდევრული ODE ამ შედეგის შემდგომ გამკაცრებას ემსახურება. მკაცრი `lambda_S -> infinity` შეზღუდვა და მინიმალური იზოტროპული განშტოება ცალკე ტოტებია და არ უნდა შეერიოს კოსმოლოგიურად კალიბრირებულ `S=6` განშტოებას.*

*ამრიგად, წინამდებარე ნაშრომი აყალიბებს RefG-ის მინიმალურ თვითკმარ ბირთვს: ფაზურ-სივრცულ EFT მოქმედებას, no-go ლემას, `S=6` თავსებადობის განშტოებას და მზის სისტემაში GR-თან თავსებადობას. შემდგომი პროგრამა მოიცავს სრული თვით-თანმიმდევრული სტატიკურ-სფერული გარე ODE ამოხსნის აგებას `S=6` შევსების წყაროთი, გლობალური და გამრუდებულ-ფონური სტაბილურობის ანალიზს, აქტიური `S/Z` ან ნაწილაკოვანი ბნელი მატერიის გარეშე CMB ბოლცმანის განშტოებას, დამატებითი გრავიტაციული ტალღური მოდების ტალღის სრული ფორმით შემოწმებას და ძლიერი ველის სექტორის განვითარებას. ამ ნაშრომის როლია ამ ამოცანების ერთ მოქმედებით ენაში მოქცევა და დაკვირვებითი კრიტერიუმების მკაფიოდ განსაზღვრა.*

## *დანართი A. უპირატესი ჩარჩოს PPN ჯაჭვი*

*ეს დანართი აჯამებს მინიმალურ `alpha_i=0` დამტკიცების ჯაჭვს. იგი იძლევა სტანდარტული PPN პარამეტრების ალგებრულ გამოყვანას იმ პირობით, რომ Solar 1PN განშტოებაზე RefG სექტორი არ წარმოქმნის დამოუკიდებელ ვექტორულ ან უპირატესი ჩარჩოს წყაროს. ეს არ არის ეფემერიდების უშუალო მონაცემებთან მორგება; სრული PPN ალბათობითი მორგება შემდგომ დაკვირვებით ეტაპად რჩება.*

*პირველი ნაბიჯი მცირე სიჩქარით გადაყვანილი ფონური სტრესის შემოწმებაა. ამ ფონზე `T_{0i}` კომპონენტის წრფივი კოეფიციენტები შეიცავს საერთო პრეფაქტორს, რომელიც Solar 1PN კოეფიციენტურ განშტოებაზე ნულდება:*

```text
K_pf -> 0,
T_{0i}^{RefG}[O(v_i)] -> 0,
T_{ij}^{RefG}[O(v_i v_j)]_anisotropic -> 0.
```

*მეორე ნაბიჯი მოძრავი წყაროს ვექტორული წევრის შემოწმებაა. შებრუნებული მეტრიკის ვექტორული პერტურბაციებით `q_{0i}=h_i` და წყაროს სიჩქარეებით `v_i` მოწმდება RefG სექტორის წყარო*

```text
d L_{RefG}/d q_{0i} = 0.
```

*წრფივ რიგში ორივე მატრიცა ნულდება Solar 1PN განშტოებაზე:*

```text
partial(d L_{RefG}/d q_{0i})/partial h_j -> 0,
partial(d L_{RefG}/d q_{0i})/partial v_j -> 0.
```

*მესამე ნაბიჯი სტანდარტულ PPN ფორმასთან შეჯერებაა. Will-Nordtvedt ფორმაში ვექტორული და უპირატესი ჩარჩოს კოეფიციენტები იწერება ასე:*

```text
V_i:        -1/2 (4 gamma + 3 + alpha_1 - alpha_2 + zeta_1 - 2 xi),
W_i:        -1/2 (1 + alpha_2 - zeta_1 + 2 xi),
w_i U:      -1/2 (alpha_1 - 2 alpha_2),
w_j U_ij:   -alpha_2,
w^2 U:      -(alpha_1 - alpha_2 - alpha_3),
w_i w_j U_ij: -alpha_2,
w_i V_i:    2 alpha_3 - alpha_1.
```

*RefG ვექტორული წყაროს არარსებობა და GR-ის ვექტორული კოეფიციენტები ერთად აყენებს შემდეგ ალგებრულ შეჯერებას:*

```text
gamma = 1,
alpha_1 = 0,
alpha_2 = 0,
alpha_3 = 0,
zeta_1 = 2 xi.
```

*აქ `zeta_1 = 2 xi` არ არის დამოუკიდებლად დახურული დაკვირვებითი შედეგი. ეს არის შეჯერების დარჩენილი არა-`alpha` პირობა, რომელიც მატერიალური პოტენციალების სრულ შეჯერებაში უნდა ჩაიწეროს. ამ დანართში დახურული უპირატესი ჩარჩოს შედეგია მხოლოდ მინიმალური ერთმეტრიკული მოძრავი წყაროს ჯაჭვის `alpha_i=0` გამოყვანა.*

*ამრიგად, მინიმალურ მოძრავი წყაროს ჯაჭვში მიიღება:*

| *პარამეტრი* | *RefG მნიშვნელობა* | *დაკვირვებითი ზღვრის რიგი* |

## *დანართი B. კინეტიკური სტაბილურობის კოეფიციენტური გამოყვანა*

*ეს დანართი წარმოადგენს მე-9 პარაგრაფში გამოყენებული კინეტიკური ფანჯრის მოკლე ალგებრულ გამოყვანას. ვმუშაობთ ერთგვაროვან, ნორმალიზებულ ფონზე:*

```text
Y = 1,
B^{AB} = delta^{AB}.
```

*ამ ფონზე მინიმალური ლაგრანჟიანის კვადრატული კინეტიკური ბლოკი ფაზური პერტურბაციისთვის `chi` და სივრცული მედიუმის გრძივი/განივი პერტურბაციებისთვის ორ მთავარ დიაგონალურ პრეფაქტორს იძლევა. ლოკალური ნიშნების დასაკონტროლებლად გამოიყენება 1PN კოეფიციენტური განშტოებიდან მიღებული კავშირები:*

```text
c_I1sq = c_Y2,
c_I1 = c_Y - 4 c_Y2 + 2 c_YI1 - 2 c_I2 - c_I3.
```

*ამ კავშირების ჩასმის შემდეგ დიაგონალური კინეტიკური პრეფაქტორებია:*

```text
K_PhiPhi = c_Y + 6 c_Y2 + 3 c_YI1,
K_pipi   = -c_Y - 2 c_Y2 - 3 c_YI1.
```

*შემოვიღოთ მოკლე აღნიშვნა:*

```text
Sigma = c_Y + 3 c_YI1.
```

*მაშინ იგივე პირობები იღებს ფორმას:*

```text
K_PhiPhi = Sigma + 6 c_Y2,
K_pipi   = -Sigma - 2 c_Y2.
```

*კინეტიკური დადებითობის აუცილებელი პირობა ორივე პრეფაქტორის მკაცრ დადებითობას მოითხოვს:*

```text
K_PhiPhi > 0,
K_pipi > 0.
```

*აქედან პირდაპირ მიიღება ორი საზღვარი:*

```text
Sigma > -6 c_Y2,
Sigma < -2 c_Y2.
```

*ამ ორ საზღვარს შორის ღია დასაშვები ფანჯარა არსებობს მხოლოდ მაშინ, როცა `c_Y2>0`. ამიტომ მე-9 პარაგრაფის კინეტიკური no-ghost ფანჯარაა:*

```text
c_Y2 > 0,
-6 c_Y2 < c_Y + 3 c_YI1 < -2 c_Y2.
```

*ეს არის ადგილობრივი დიაგონალური კინეტიკური დადებითობის ზუსტი ალგებრული პირობა შერჩეულ ერთგვაროვან ფონზე. იგი აუცილებელია, მაგრამ თავისთავად არ ხურავს გრადიენტულ სტაბილურობას, შერეულ მოდებს ან გლობალურ ჰიპერბოლურობას.*

*გრძივი შერეული სექტორის ლოკალური principal-symbol ტესტი იწერება კვადრატული პოლინომით:*

```text
det M(s) = p2 s^2 + p1 s + p0,
s = omega^2/k^2.
```

*თუ ფაზურ-გრძივი ბლოკის კოეფიციენტები აღინიშნება `A`, `B_L`, `C`, `D`, `M`-ით, მაშინ:*

```text
p2 = A B_L,
p1 = A D + B_L C - M^2,
p0 = C D.
```

*ორი რეალური და დადებითი გავრცელების სიჩქარისთვის საჭიროა:*

```text
p2 > 0,
p1 < 0,
p0 > 0,
p1^2 - 4 p2 p0 >= 0.
```

*ეს კრიტერიუმი ამკაცრებს ზემოთ მიღებულ კინეტიკურ ფანჯარას. არსებობს მინიმუმ ერთი არაცარიელი პარამეტრული წერტილი, სადაც როგორც დიაგონალური no-ghost ფანჯარა, ისე ლოკალური შერეული მოდების principal-symbol პირობები სრულდება; ამიტომ დასაშვები არე ცარიელი არ არის. მიუხედავად ამისა, ეს რჩება ლოკალურ ჰომოგენურ-ფონურ ტესტად და არ წარმოადგენს სრულ გამრუდებულ-ფონურ ან არაწრფივ სტაბილურობის მტკიცებულებას.*
