# RefG Genesis Scenario

This isolated Work-3 folder develops one candidate Genesis picture without
editing the intuitive manuscript or importing an upstream result artifact.

The candidate ordering is:

1. one finite, global, centerless initial boundary;
2. the first minimally distinguishable relations;
3. proto-oscillon localization;
4. post-relation tail formation and overlap;
5. relational-network spanning/percolation;
6. later stable material oscillons and continuing relaxation.

The folder contains three deliberately separate gates:

- W3-37 checks causal/domain separation. It prevents a propagating tail from
  being used as the cause of the relations required for propagation.
- W3-38 gives a conditional finite-graph witness for centerless connectedness
  and post-adjacency tail-overlap spanning. It does not select cosmic topology.
- W3-39 checks energy-transfer, moving-boundary, phase-conversion signs, and a
  conditional symmetry no-go for one strictly distance-graded centered-birth
  record in a homogeneous Genesis.

PASS in these gates means exact algebraic or logical consistency only. The
Genesis action, initial-state selection, topology, tail PDE, energy-transfer
rates, stable-oscillon spectrum, thermal history, and observations remain
OPEN.
