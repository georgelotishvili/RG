## ძირითადი შედეგი

მთელი იზოლირებული სხეულის ენერგია–იმპულსი იძლევა

    E = gamma E0, P = gamma E0 v/c0^2, M_I = E0/c0^2.

ინერცია აქტიურ ასიმპტოტურ გრავიტაციულ მასას ემთხვევა. სუსტ, ნელა
ცვალებად გარე ველში იმავე მასით განისაზღვრება წამყვანი პასიური
გრავიტაციული პასუხი. მატერია და სინათლე ერთ მეტრიკას უკავშირდება.
საათისა და სახაზავის ფაქტორები ამავე განტოლებებიდან დამოუკიდებლად
მიიღება: `p_T=N`, `p_L=1/A_iso`, `c_coord=c0 p_T p_L`.

ფიქსირებულ `alpha=.001`, `Q=190.401136223484`-ზე მიღებულია შეკრული
ოსცილონი: `M_ADM=176.770354877229`. შემოწმებულია წყაროს დაძაბულობის
შესაბამისობა გეომეტრიასთან, `dM/dQ=Omega` და სრული ფიქსირებული-მუხტის
რადიალური ენერგეტიკული ფორმის დადებითობა გამოცდილი ბადეებისა და
რადიუსებისთვის.
