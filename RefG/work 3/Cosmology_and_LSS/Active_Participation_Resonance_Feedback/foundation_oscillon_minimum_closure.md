## 1. ერთი მდგომარეობა და მისი საზომები

p>0 არის საერთო უგანზომილებო მასშტაბური ფაქტორი, t — გარე საყრდენი
საათი, tau — შესაბამისი ადგილობრივი პროცესული საათი. შენარჩუნებულია
არსებული ერთობლივი ამოკითხვა:

    d tau = p dt,
    L_ext/L_local = m_eff/m_0 = Omega_t/Omega_local = p,
    c_coord/c_0 = p^2.

შესაბამისი სტატიკური/თანამოძრავი ადგილობრივი ჩარჩოს მეტრიკული ფორმაა
(აქ და ქვემოთ c_0=1, ხელმოწერა -+++):

    ds^2 = -p^2 dt^2 + p^-2 delta_ij dx^i dx^j.

ცვლადი p-ისას d tau=p dt და d ell=|dx|/p ადგილობრივი საზომი ფორმებია.
tau=p*t, X=x/p გლობალური კოორდინატული ჩანაცვლება მხოლოდ მუდმივ p-ზე
გამოიყენება. დინამიკურ ან ნაკადიან გარემოში ჩარჩო და მსოფლიო ხაზები
იგივე მოქმედებიდან უნდა განისაზღვროს.

ძველი კოსმოლოგიური ლექსიკონი განასხვავებს განზომილებიან ფონურ
წნევის ამოკითხვას P_F და მასშტაბურ ფაქტორს:

    P_F/P_F0 = p^2,       dP_F/dt = 2 P_F0 p dp/dt.

ეს არსებული არჩევანია; P_F=p P_F0-ით მისი ჩანაცვლება კანონის ცვლილება
იქნებოდა. თერმოდინამიკური წნევა Pi_C ცალკე მოქმედების ვარიაციით იკითხება.

**სტატუსი:** საზომების ლექსიკონი არსებობს. კონკრეტული არაერთგვაროვანი

ველს, A_mu — სინათლის/მაქსველის ველს. ეს მოქმედებების აღრიცხვაა:

## 3. ენერგიის გადაცემა, მუშაობა და ერთი ბალანსი

ერთი და იმავე ადგილობრივი მდგომარეობის მუდმივი p-ით შედარებისას:

    E_t = p E_local,       Power_t = p^2 Power_local.

ორივე ფაქტორი უკვე შემოწმებულია [საათისა და გადაცემის აუდიტში](oscillon_clock_transfer_audit.md).
ერთი მცირე ადგილობრივი ენერგეტიკული პაკეტისთვის ან ერთგვაროვნად
გადამასშტაბირებული ქვესისტემისთვის, სადაც E_t=p E_local მოქმედებს,
ცვალებად p-ზე ენერგიის ამოკითხვის ზუსტი ჯაჭვის წესია

    dE_t/dt = (dp/dt) E_local + p^2 dE_local/dtau.

პირველი წევრი ცვლადი გარემოს მუშაობის აღრიცხვას მოითხოვს;
მეორე ადგილობრივი ენერგიის ცვლილებას აღწერს. მუდმივი p-ის
ნაკადის ფორმულა ამ სრულ წარმოებულს ვერ ჩაანაცვლებს.
არაერთგვაროვანი მთელი სხეულისთვის p(x) სივრცული ენერგეტიკული
ინტეგრალის შიგნით რჩება; ერთი საერთო მამრავლით გამოტანა დამატებით
პირობას მოითხოვს. საზღვარი და, შესაბამის ჩარჩოში, ცვლის ვექტორის
წვლილი იმავე აღრიცხვაში შედის.

მეტრიკასთან დაკავშირებული სექტორების საერთო ადგილობრივი ბალანსია

    nabla_mu T_total^{mu nu} = 0.

თუ შერჩეული მოქმედება რეალურ სექტორულ გაცვლას წარმოქმნის:

    nabla_mu T_oscillon^{mu nu} = Q^nu,
    nabla_mu T_foundation^{mu nu} = -Q^nu

შესაბამისი სხვა არხების გათვალისწინებით. ცალკე Q=0-იც უშვებს
საერთო გეომეტრიის გავლით ურთიერთქმედებას.
ინტერაქციის ენერგია ერთხელ უნდა იყოს აღრიცხული.

მარტივ ერთმდგომარეობიან შემცირებაში, მხოლოდ მისი დასაბუთების შემდეგ:

    C(p) = dU_total/dp,
    C(p) dp/dt = Power_in - Power_out + Work_rate.

ეს გვიჩვენებს რა საჭიროა ენერგიის ტემპიდან წნევის ცვლილებაზე გადასასვლელად:
იმავე მოდელიდან მიღებული ენერგეტიკული პასუხი C და მუშაობის წევრი.
გრავიტაციულ სისტემაში U_total-ისა და საზღვრის განსაზღვრაც აუცილებელია;
ლოკალური მატერიის ენერგიის შეკრება ავტომატურად სრული მასა არ არის.

**სტატუსი:** ბალანსის ფორმა და მუდმივი p-ის გადაყვანა ცნობილია.

  მოცემულია [ფორმალურ ჩაშენებაში](../../Strong_Field/W3-92_Covariant_Medium_Integration/FORMAL_COVARIANT_MEDIUM_INTEGRATION.md).

## 5. წონასწორობა და ნულამდე მიუღწევლობა

ფიქსირებულ მატერიულ დატვირთვაზე უნდა მოიძებნოს p_*>0 წონასწორობა
ყველა საწყისი განტოლებიდან. ინერციულ აღწერაში მცირე გადახრის
საკმარისი მარტივი ტესტია

    M delta_p'' + D delta_p' + K delta_p = 0,
    M>0, K>0, D>=0.

წარმოებულები აქ არჩეული ადგილობრივი დროითაა; M,D,K იმავე მოქმედებიდან
ან დასაბუთებული ეფექტური შემცირებიდან მიიღება. D=0 აღდგენით რხევას
უშვებს; მილევა ენერგიის შესაბამის არხს მოითხოვს. მრავალველიან შემთხვევაში
მოწმდება შესაბამისი შეზღუდული ფიზიკური რეჟიმები, არა ერთი თვითნებური
delta_p განტოლება.

მონოტონური კლების განშტოებაზე დავწეროთ dp/dt=-R(p), R>0.
ზუსტი დროითი კრიტერიუმებია

    t_zero - t0   = integral_0^p0 dp/R(p),
    tau_zero-tau0 = integral_0^p0 p dp/R(p).

განსხვავებული საათების ეს ორი ინტეგრალი ძლიერ ველამდეც გასარჩევია.
ორივე საათში მიუღწევლობის უკვე გამოყვანილი საკმარისი პირობაა

    Gamma = -(1/p) dp/dtau = R/p^2,
    0 <= Gamma <= Gamma_max < infinity along the solution.

იგი იძლევა

    p(t) >= p0/[1+Gamma_max p0(t-t0)],
    p(tau) >= p0 exp[-Gamma_max(tau-tau0)] > 0.

Gamma-ს ზღვარი უნდა მივიღოთ საპასუხო კანონიდან, არა სურვილით დავაწესოთ.
ზემო ერთმდგომარეობიან დანაკარგის აღწერაში, თუ C(p)>0,
Power_local(p)>=0 და C(p)dp/dt=-p^2 Power_local(p),
მაშინ Gamma=Power_local/C. C=0 წერტილში ეს გაყოფა აღარ გამოიყენება.
ასე ზუსტად ჩანს ენერგიის ორმაგი შემცირებისა და წნევის ცვლილების კავშირი.

W75-ში შესაბამისი ზღვარი უკვე დინამიკურადაა მიღებული ერთგვაროვანი
გაფართოებისთვის: Gamma=3H/5 და 0<H<=H_i.
არაერთგვაროვანი მდგომარეობის შედეგი საკუთარ განტოლებებს უნდა დაეყრდნოს.
